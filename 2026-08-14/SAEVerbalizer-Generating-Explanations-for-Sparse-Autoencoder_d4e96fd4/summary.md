# 论文速读：SAEVerbalizer-Generating-Explanations-for-Sparse-Autoencoder

## 一句话总结
本文提出 SAEVERBALIZER，通过将 SAE 解码器方向直接注入 LLM 隐层表示并微调下游参数，使模型学会用自然语言直接解释稀疏自编码器特征；该方法彻底跳过外部激活样本检索，实现特征解释的快速泛化、跨字典复用与跨模型迁移。

## 研究问题与动机
1. 现有 SAE 特征解释高度依赖外部行为观测（提取 top-activating 样本并用 LLM 总结），只能推断激活文本的浅层共性，难以触及特征在 LLM 内部表示空间中的真实语义。
2. 每引入新 SAE 或新特征都需重复大规模语料推理、激活计算与样本检索，计算开销随特征数量线性放大，严重限制可解释性工具的可扩展性。
3. 现有方法分属自底向上（基于激活样本归纳）与自顶向下（基于预定义概念定位）两类，前者效率低且易受噪声干扰，后者依赖人工假设且无法穷举所有特征。
4. LLM 自发内省解码隐状态的能力不稳定且对提示敏感，缺乏将 SAE 解码器方向系统转化为自然语言的 trainable 机制。

## 核心贡献（创新点）
1. 提出 SAEVERBALIZER 框架，将 SAE 特征解释从“观测外部行为”转向“处理内部表示”。与现有方法本质区别在于完全跳过激活样本检索与外部语料推理，仅以解码器方向作为唯一特征特定输入。
2. 设计基于特征-解释对的自动化监督构建流程，利用 LLM Judge 对 Neuronpedia 现有解释进行两阶段质量过滤（一致性、特异性、匹配覆盖率）。与依赖人工标注或自发生成解释的已有工作不同，提供了一套可扩展的数据清洗与微调 pipeline。
3. 证明表征解释能力可泛化至未见特征、跨独立训练的 SAE 字典直接复用，并引入轻量级仿射 Adapter 实现跨 LLM 表示空间对齐。与需针对每个模型/字典重新训练的基线相比，大幅降低部署
