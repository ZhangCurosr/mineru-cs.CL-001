# 论文速读：OmniScientist-An-Omni-Modal-Omni-Discipline-AI-Scientist

## 一句话总结
OmniScientist是一个端到端、全模态、跨学科自主科学发现的AI科学家系统，能够直接从异构原始科学证据（图像、信号、音频、视频、3D结构、轨迹、表格、公式、图等）出发，通过感知层与三阶段代理（构思-实验-写作）的协同，自动生成完整的可发表研究论文。

## 研究问题与动机
1. **证据接口缺失**：现有AI科学家系统虽然覆盖了完整研究工作流程，但仅能处理文本、代码、标签或预计算摘要，原始证据中的空间、时间、跨通道和程序性关系在预处理阶段被丢失。
2. **感知能力局部化**：科学多模态基准固定观察对象和问题，而使用感知的科学代理仅在局部阶段调用（如检查图表、评分绘图），无法建立"观察→问题生成→实验设计→结论支撑"的闭环研究循环。
3. **验证机制脆弱**：现有系统依赖模型自评估进行阶段转换和结果验证，容易受到幻觉、统计操纵（如HARKing）、多重复比较等问题影响，缺乏确定性保障。

## 核心贡献（创新点）
1. **感知优先的三代理架构**：提出感知层与构思、实验、写作三个自主代理协同的端到端框架，原始观测可贯穿整个研究生命周期指导问题形成、实验设计和最终声明，区别于仅处理预计算摘要的现有系统。
2. **代码级执行检查机制**：设计idea check、rigour check、claim check三个确定性代码谓词，强制验证新颖性、统计有效性、执行可追溯性和防HARKing约束，而非依赖模型自评估。
3. **学科无关的证据家族分类**：将科学证据按推理范式分为感知型、符号型、定量统计型和程序型四类，同一引擎可无缝运行于地震图、病理切片、3D CAD等不同模态，无需领域特定代码。
4. **36案例跨学科验证**：建立涵盖5个学科领域、11种模态的演示集，系统在所有案例中完成从原始数据到编译论文的全流程，且直接感知相比盲变体（仅预计算标量）在85%对战评判中胜出。

## 方法详解
**整体架构**：由感知层和三个顺序阶段组成，每个阶段内嵌ReAct循环，阶段间由确定性代码谓词控制。

1. **感知层（Perception Layer）**：
   - 将原始证据按推理范式分类为4个证据家族，每种模态注册专用工具（如`look_at_image`、`analyze_signal`、`read_trace`等）
   - 支持视觉通道（渲染后查看）和原生数字通道（提取FFT峰值、统计量等），根据任务上下文动态选择
   - 视觉感知预算受限：`min(24, max(8, 2k))`次检查（k为标签类别数）

2. **构思代理（Ideation）**：
   - ReAct循环：枚举材料→文献搜索（OpenAlex/Crossref）→生成≥5候选想法→评估新颖性/可行性→选定并完善
   - **idea check**验证：结构完整性（研究问题、假设、实验方案、可证伪标准）、广度（≥5候选、≥3次文献搜索）、可行性（完全计算，无需湿实验）、有效样本估计、泄露检查、视觉审计、新颖性语言限制

3. **实验代理（Experiment）**：
   - 迭代代码生成：通过`run_python`执行，至少包含4种分析（主要检验+基线+消融+机制/敏感性/分解）
   - **rigour check**（Algorithm 1）：
     - 指标非空、有成功执行记录
     - 所有报告数字必须在stdout中可追溯
     - 数据集必须从磁盘加载
     - 多重比较校正覆盖所有测试（含降级分析）
     - 头题必须来自支持的检验，非显著分析降级到trace

4. **写作代理（Writeup）**：
   - 5种结构规范（机器学习、生物医学、地球与空间、物理、化学），每部分仅从实验记录对应切片生成
   - **claim check**：所有数字匹配实验记录、保护性修订（若改动数字/引用/声明则回滚）、禁止过度声明、最终编译前meta-audit

5. **异常处理**：实验失败或结果为null时回退到构思阶段（最多2次回退），超出步预算则终止。

## 实验与结果
1. **数据集**：36个真实公开数据集，覆盖5个学科（物理科学、地球与空间、生命与医学、农业与生态、工程与信息）、4类证据家族、11种模态，样本量从12个公式到500万边知识图谱不等。

2. **评估设置**：
   - 9个推理主干对比（Claude Sonnet 5、GPT-5.6、GLM-5.2、Kimi K2.7、Qwen3.5-9B/27B/122B、Gemma-4-26B/31B）
   - 7维评审标准（novelty、soundness、clarity、significance、reproducibility、mm_grounding、factual_accuracy），0-10分
   - 2位跨领域评审员（deepseek-v4-flash、gemini-2.5-flash-lite）
   - 盲变体：仅接收预计算标量特征，无原始感知

3. **主要结果**：
   - 36案例全部完成端到端研究，Sonnet 5平均总体评分6.3
   - 感知vs盲变体：直接感知提升全部7维度，最大增益在multimodal grounding（+2.8）和significance（+1.8），85%对战胜出
   - 事实准确性始终最高（平均7.7），所有模型均表现一致
   - 跨学科/模态中位数评分6.1-7.1，高度稳健
   - Ablation：先验搜索和迭代代理循环最关键，移除先验搜索导致评分从6.9降至5.7

4. **典型案例**：
   - 地震学：发现21.7%（163/750，CI [18.8, 24.9]）噪声标注地震图携带相干极化瞬态信号
   - 儿科胸部X光：肺炎肺野空间异质性（patchiness）与正常肺分离效应量d=1.25，AUC 0.85 vs 原始像素0.63

## 相关工作脉络
1. **Co-Scientist / A-Scientist-v2 / Agent Laboratory**：覆盖完整研究流程但仅处理文本/代码/预计算摘要，OmniScientist通过直接感知原始证据实现证据完整性。
2. **MMMU / CharXiv / SciFIBench**：固定观察对象和问题，将感知作为独立QA技能评估；OmniScientist将感知嵌入开放研究循环。
3. **ScienceBoard / OR-GANA**：仅在局部阶段使用感知（如检查图表、监控仪器）；OmniScientist建立全生命周期感知闭环。
4. **AlphaFold / 自主化学实验室**：针对单一领域设计；OmniScientist通过证据家族分类实现跨学科通用性。
5. **虚拟实验室 / 研究者生态系统**：通过提示和生成消息编排代理，阶段转换依赖模型输出；OmniScientist用代码谓词控制确定性管道。

## 局限性与未来方向
1. 当前仅支持完全计算的研究（排除湿实验），依赖现有LLM推理能力，复杂任务（如Sleep-EDF）仍存在失败案例。
2. 视觉感知预算受限，3D结构等模态解析能力受限于当前VLM水平。
3. 评估依赖人工审稿评分，缺乏与真实科学家的对照实验，未量化发现的实际科学价值。
4. 未来可扩展至真实实验室操作、更复杂的动态环境、以及更多学科领域。

## 研究启发与可借鉴点
1. **代码级检查替代模型自评估**：将验证逻辑转化为确定性谓词（检查数值可追溯性、多重比较校正覆盖范围等），可有效防止幻觉和统计操纵，适用于任何需要严格验证的Agent系统。
2. **感知驱动的假设生成**：让原始观测而非预计算摘要引导问题形成，显著拓宽假设空间和发现潜力，可迁移至数据分析、异常检测等场景。
3. **HARKing防护框架**：头题归因、非显著分析降级、多重比较校正覆盖所有尝试测试等策略，为自动化科学研究提供可复用防偏差机制。
4. **规范文件驱动的新学科扩展**：仅需编写任务规范文件（角色、数据描述、模态）即可支持新领域，无需修改核心管道，降低系统适配成本。
5. **执行记录作为单一可信源**：统一记录数据I/O、stdout、图表、所有测试（含失败），便于追溯和验证，可应用于其他需要可复现性的AI系统。

## 关键术语表
1. **OmniScientist**：端到端全模态AI科学家系统，直接从异构原始科学证据出发自主完成研究全流程。
2. **ReAct循环**：Reasoning + Acting交互模式，代理在每步交替进行推理和工具调用以完成复杂任务。
3. **HARKing**：Hypothesizing After Results are Known，在已知实验结果后提出假设的科研不端行为。
4. **证据家族分类**：按推理范式将科学证据分为感知型（图像/信号）、符号型（文本/公式）、定量统计型（表格/分布）、程序型（轨迹/模拟）四类。
5. **rigour check**：代码执行的实验结果验证检查，确保统计有效性、执行可追溯性和防HARKing。
6. **claim check**：代码执行的写作阶段检查，验证论文声明与实验记录的完全一致性。
7. **perception layer**：跨模态原始数据读取层，支持视觉通道和原生数字通道，按证据家族和模态动态解锁工具。
8. **execution record**：执行记录，统一记录数据I/O、标准输出、生成图表和所有测试的权威日志，作为所有检查的事实源。

## 可复现要素
- **数据集**：36个真实公开数据集（STEAD、EuroSAT、Kather CRC、Galaxy Zoo、Feynman等），均有公开下载链接和引用
- **代码/权重**：软件已开源（https://github.com/Omni-Scientist/OmniScientist），项目页面（https://omni-scientist.github.io）
- **关键超参**：
  - 构思阶段：最大24步，8次文献查询，视觉预算min(24, max(8, 2k))
  - 实验阶段：最大50步，8次视觉检查，每次run_python 150秒超时
  - 回退上限：最多2次回退到构思阶段
  - 文本生成：每次调用上限8000 tokens
- **推理模型**：主实验使用Claude Sonnet 5，对比GPT-5.6、GLM-5.2、Kimi K2.7、Qwen3.5系列、Gemma-4系列
- **感知模型**：固定为Claude Sonnet 5
- **评审模型**：deepseek-v4-flash、gemini-2.5-flash-lite
