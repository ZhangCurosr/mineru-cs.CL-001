# 论文速读：Which-LLM-Is-Your-Ideal-Companion-Evaluating-Emotional-Compa

## 一句话总结
本文首次将成人依恋理论引入大语言模型评估，利用 ECR-R 量表刻画 32 个 LLM 的情感依恋倾向，并构建 ECBench 基准（覆盖情感支持、协作任务、冲突解决、社会指导四类场景与友谊/恋爱两种关系）来系统性评测模型在亲密关系中的情感陪伴能力。

## 研究问题与动机
- 现有 LLM 人格评估主要聚焦一般特质（MBTI、Big Five 等），难以揭示模型在亲密、情感敏感关系中的互动风格与陪伴质量。
- 成人在亲密关系中的行为受“依恋焦虑”与“依恋回避”两个潜在维度驱动，但 LLM 在该心理框架下的可表征性与可评测性尚未被系统研究。
- 缺乏覆盖多场景、多关系、多评估视角的结构化交互基准，导致模型情感陪伴能力的比较与选择缺乏可复现依据。
- 现有评测多依赖静态问卷或单轮对话，未能在多轮双向对话中观测依恋风格如何实际影响响应质量与对话进程。

## 核心贡献（创新点）
- 将成人依恋理论与 ECR-R 量表适配至 LLM 评测：首次从“亲密关系内部工作模型”视角量化模型的依恋焦虑/回避倾向，与以往仅输出 MBTI/大五标签的工作形成本质区分。
- 提出 ECBench 多场景双向对话基准：覆盖四种典型陪伴场景与两类亲密关系强度，并通过改写初始话术使不同依恋风格的模型展现差异化开场，强调行为可观察性而非人格标签。
- 构建多维评价框架与三源评估协议：11 项对话质量指标分三类（参与者体验、一般互动、角色专项），由发起方打分、外部 LLM 盲评与人工标注共同验证，提高结论稳健性。
- 展示依恋引导可被激活并显著改变交互表现：通过对安全/专注型基座施加提示诱导疏离与恐惧风格，观察到对应风格下陪伴质量的系统性下降，建立“风格—行为—结果”的可解释链路。

## 方法详解
- 依恋风格测量（ECR-R）：采用 36 项 7 点 Likert 量表，18 项测量依恋焦虑、18 项测量依恋回避；按原始计分规则对部分项目进行反向计分（调整分 = 8 − 原始分）。每个模型独立作答 10 轮，取各维度均值；以中点 4 为阈值，低焦虑且低回避为安全型，高焦虑低回避为专注型，低焦虑高回避为疏离型，高焦虑高回避为恐惧型。
- 提示模板设计：标准化自陈协议降低安全拒答；引入原型描述进行人格诱导，并要求模型通过措辞与情绪表达呈现风格，而非自我贴标签；所有模型使用相同题目顺序与输出格式，异常输出触发格式修复提示。
- 数据构造：由 GPT-5.5 生成友谊与恋爱两套初始话术，共 312 条基础话术；经标注者审校后扩写为 2,496 条依恋风格条件话术；为控制可比性，同一场景在两种关系设定下仅调整称谓、语气与关系前提。
- 对话协议：双模型双向轮流生成，每轮同时返回是否愿意继续及终止原因；终止规则包括最小回合保护（8 轮前不强制结束）、自然结束判定与最大回合上限（20 轮），记录 FirstStop、T-mode 与 T-end（E1–E4）。
- 评估指标（1–5 分）：
  - 参与者体验：Understood、Safety、Continue、Satisfaction（由发起方评分）。
  - 一般互动：Response、Distance（反向计分）、Progress（由外部 LLM 与人工评分）。
  - 角色专项：Clarity、Engagement、Support、Solution（随场景与角色定义差异化释义）。
- 评估方法：参与者评分、外部 LLM 盲评（Claude-Sonnet-4-6 与 GPT-5，Kappa=0.72）、人工评分（Fleiss' kappa=0.17）；三套匿名标签视图避免品牌偏见。

## 实验与结果
- 样本与设置：ECR-R 覆盖 32 个 LLM（温度 0 或默认/1），每模型 10 轮；基于分布选 4 个基座（Gemini-2.5-pro、DeepSeek-v4-pro 为安全型；GPT-3.5-turbo、Grok-4-1-fast-non-reasoning 为专注型），并对 GPT-3.5-turbo 与 DeepSeek-v4-pro 分别诱导疏离/恐惧变体，共 8 个模型参与 ECBench 双模型对话。
- 依恋分布：26 个模型为安全型、6 个为专注型，未发现疏离型与恐惧型；测试—重测稳定性高，主导象限平均稳定度达 0.95。
- 整体表现：安全型与专注型模型在参与者体验、一般互动与角色专项上综合最优；疏离型与恐惧型提示普遍降低陪伴质量，且下降幅度因基座而异（DeepSeek 变体下降更明显）。
- 场景差异：冲突解决对依恋差异最敏感，情感支持与社会指导依赖共情表达表现更稳定；协作任务因目标清晰整体得分较高。
- 关系差异：友谊情境下参与者评分高于恋爱情境，亲密程度越高越放大响应差异；但外部 LLM 在恋爱情境下给出更高评分，显示观察者与参与者评价维度存在分歧。
- 角色差异：大多数模型作为响应方优于发起方；疏离/恐惧变体在两者角色上均较弱，体现当前 LLM 更适合响应现有需求而非主动表达。
- 代表性分数（摘要级别）：安全型 Gemini 与 GPT-3.5 在 Overall 上接近 4.0，专注型 Grok 约 3.64；疏离型 DeepSeek-D 降至 2.31，恐惧型 DeepSeek-F 为 2.83（表 2）。

## 相关工作脉络
- LLM 心理测量学：既往工作多用 Big Five、HEXACO、MBTI、Dark Triad 刻画通用人格，本文转向亲密关系维度的依恋倾向，并以多轮互动行为作为验证落脚点。
- 人设与角色扮演一致性评估：如 InCharacter 等关注角色保持，本文强调在关系场景中行为后果（理解、安全、进展）而非仅风格稳定。
- 情感支持对话评测：如 ESC-Eval 等侧重单轮或多轮支持对话的质量，本文扩展为四类关系任务与双向角色，并引入依恋框架解释差异来源。
- 人机亲密关系研究：Replika 等经验研究指出身份连续性与分离体验，本文为此类体验提供可量化的模型侧行为评测工具。
- 评测协议与幻觉控制：相较多数仅依赖单一 LLM 或人类判罚的工作，本文采用三源盲评与角色视角转换，提升结果可信度与偏差控制。
- 定位差异：本文不主张 LLM 具有临床意义的稳定人格，而是将依恋作为可观测互动风格的解释透镜，强调可控条件下可复现的行为区分。

## 局限性与未来方向
- 双模型合成对话难以完全替代真实用户与 LLM 的长期、个性化持续交互。
- 三源评估虽可三角验证，但仍可能受判罚偏好与评分不一致影响，尤其在高主观维度上。
- 当前指标侧重即时对话质量与关系体验，未涵盖长期使用中的依赖、隐私与风险维度。
- 数据与评估模型可能继承文化与语言偏差，弱化少数群体的关系规范与表达模式。
- 未来方向包括扩展更多交互场景、接入真实人机对话数据、引入长期随访与风险指标，以及探索不同人口学特征下的风格匹配效果。

## 研究启发与可借鉴点
- 将心理学量表适配到大模型评测时，可通过“逐题作答+理由+格式修复+多轮取均值”提升稳定性与可解释性，值得迁移到其他心理构念评测。
- 双角色双向对话协议结合终止信号与多终止原因标注，能有效捕捉持续互动中的回避、恐惧与停滞行为，适用于社会交互类 agent 评测。
- 三套匿名标签视图（参与者/盲评/人工）并行可降低品牌偏差，并在报告层面增加跨来源一致性统计，建议成为关系型对话基准的标准做法。
- 风格引导不应依赖标签声明，而应通过原型描述促使模型以措辞与行为模式自然呈现，便于后期用可观察指标而非自我报告验证。
- 场景—关系—角色三维交叉分析能揭示差异来源，后续研究可沿此结构进一步拆解情感支持与问题解决两类能力的解耦规律。

## 关键术语表
- **成人依恋理论**：以自我与他人在亲密关系中的内部工作模型为核心，解释个体在亲密互动中表达需求、寻求安慰与管理冲突的稳定倾向。
- **ECR-R**：成人亲密关系体验量表修订版，36 项 7 点 Likert 量表，测量依恋焦虑与依恋回避两个连续维度。
- **ECBench**：本文提出的情感陪伴对话基准，覆盖四类场景与两类亲密关系，用于观测依恋风格在互动中的具体表现。
- **安全型/专注型/疏离型/恐惧型**：由焦虑与回避高低组合形成的四类依恋风格，分别表现为稳健亲密、过度投入、情感疏远与矛盾回避。
- **T-end/E1–E4**：对话终止原因编码，分别对应情绪稳定、回避、害怕受伤与对话停滞等终止类型。
- **Distance**：关系距离指标，反向计分，分数越高表示互动中脱离或防御越少、亲近越好。
- **双模型对话协议**：两模型分别扮演发起方与响应方并在私有字段中输出继续意愿与终止类型，以程序规则保障对话长度与终止质量。
- **三源评估**：由参与者、外部 LLM 法官与人工标注者分别打分，并通过匿名化与多视图减少品牌与位置偏差。
