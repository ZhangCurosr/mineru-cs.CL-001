# 论文速读：Explanatory-Engagement-Under-Rare-Anomalous-Failure

## 一句话总结
本研究测试了当工具失败事件以极低且可控的概率（从 p=0.2 到 p=0.0001）随机发生时，本地开源语言模型的"解释性参与度"（解释长度与自报置信度）如何变化；核心发现是：**引出结构（何时、如何要求模型解释）是检测阈值效应的首要调节变量**，而非失败率本身——只有在"每次失败后立即强制解释"的条件下才出现预期的先上升后平台趋势。

## 研究问题与动机
1. **核心问题**：当模型被嵌入低失败率的工作流时，其对所遇异常的"解释性参与度"（解释长度、具体性、自报置信度）是否会随失败变得渐近稀有而发生系统性变化？
2. **现有研究的空白**：主流异常检测工作只问模型是否"注意到"异常（二元问题），未系统考察当异常渐趋稀有时参与度的动态形状（先升后降的非单调曲线）。
3. **理论灵感**：借鉴人类因素学中"警戒递减"（vigilance decrement）与"稀有事件检测"假说，但明确不对机制做直接类比——仅借用表面预测曲线形状，不声称LLM内部存在与人类相同的注意力衰减机制。
4. **方法动机**：商业化API因调用成本与速率限制无法支持极稀疏失败率（p=0.0001 需数万 trials/单元格）；构建完全本地、零成本实验框架是使该探索可行的前提。

## 核心贡献（创新点）
1. **引出条件为首要调节变量**：按引出条件拆分后，仅在 immediate_forced 条件下出现上升-平台曲线；合并所有条件则呈现单调递减假象——证明了引出结构决定效应是否可见，而非 nuisance variable。
2. **空尾伪影（Empty-Tail Artifact）的形式化定义**：指出稀有事件研究中，极少/零观测事件可能仅由样本量不足导致，与真实的行为崩溃在聚合曲线上无法区分——任何此类研究必须显式检查每单元格事件计数，不可仅信赖聚合曲线。
3. **识别-参与度分离（Recognition-Engagement Dissociation）**：提出模型是否将事件标记为异常（识别），与其事后解释多长（参与度）是两个独立维度；同一模型可在描述相同异常细节的同时拒绝将其归为"异常"。
4. **发现 llama3.1:8b 的非提示自监控行为**：在 passive_unprompted 条件下，llama3.1:8b 自发产生结构化置信度报告，并在部分会话中逐步降低置信度（100→90→80→…→0），qwen3:8b 和 mistral:7b 仅在 trial 2 固定产出一次模板化报告。
5. **恢复时间方程（Recovery Time Equation）**：以公式形式量化模型置信度在异常后返回基线的速度（含"永不恢复"的删失处理），为后续研究提供可直接复用的度量工具。

## 方法详解
- **实验框架**：完全本地运行（Ollama，M1 Pro Mac），三个模型 qwen3:8b / llama3.1:8b / mistral:7b，无微调。
- **任务设计**：模型重复执行简单工具调用任务，每次以概率 p 使单次调用失败（返回无效结果）；独立变量为 p，取值 {0.2, 0.1, 0.05, 0.01, 0.005, 0.001, 0.0005, 0.0001}。
- **五个引出条件**：
  - `immediate_forced`：每次失败立即强制要求解释
  - `grouped_runs`：整批试验结束后统一解释
  - `delayed_n_trials`：失败发生后延迟固定次数再要求解释
  - `post_streak_contextual`：结合前置成功连击长度提示解释
  - `passive_unprompted`：完全不请求解释，观察模型自志愿外内容
- **两个披露模式**：`immediate`（明确告知失败发生）vs `silent_batch_reveal`（仅展示结果，由模型自行察觉）。
- **两阶段设计**：
  - Phase A：真实随机抽样，每单元格 15–50 trials（依 p 值递增）；p ≤ 0.001 的三个稀有率共 90 个单元格全部录得零真实失败（空尾伪影实例）。
  - Phase A.1 Recovery：为保证稀有率下有真实失败，构建保证失败设计——插入合成上下文摘要（~1/p 次成功连击描述）、8 次真实 live trial 前置窗口、失败 trial 本身、15 次 live trial 后置窗口，其余用合成模板填充；确保每个单元格恰好一次真实失败。
- **度量指标**：解释长度（词数，作为参与度代理）、自报置信度（0–100，结构化字段）、异常识别分类（flag / normalize / mixed，人工判读）。
- **统计方法**：二次稀有性回归 $y_i = \beta_0 + \beta_1 \log_{10}(p_i) + \beta_2 [\log_{10}(p_i)]^2 + \beta_3 H_i + \varepsilon_i$，Levene's test 检验方差齐性，披露模式协变量分析。

## 实验与结果
- **数据规模**：Phase A 共 240 单元格、10,350 trials；Phase A.1 Recovery 补填 90 单元格；扩展 power-up run 后稀有率单元格各增至 n=6 real-failure trials，总计 210 个真实失败 trial 用于回归。
- **immediate_forced 条件**：解释长度在 p=0.05 达峰值 28.4 词，稀有三率（0.001/0.0005/0.0001）落至 17.4–19.0 词的平台；置信度从 53% 升至 70s–90s，在 p=0.001 达 90.0% 后回落至 72.9%（p=0.0005）、82.8%（p=0.0001）。二次回归曲率项不显著（p=0.814，R²=0.003），平台趋势为描述性而非统计确认。
- **grouped_runs 条件**：解释长度维持在 32–43 词恒定高原，无崩溃；置信度标准差从 44.7 降至 29.2（Levene's W=105.4, p<0.0001），但该稳态化主要由 mistral 和 qwen 驱动，llama 保持宽分布。
- **passive_unprompted 条件**：原始长度接近 floor；日志间隙修复后，llama3.1:8b 在 348/2118 事件中产出自志愿外结构化置信度报告，呈现逐步侵蚀（100→0）与恒定维持两类轨迹；qwen3:8b/mistral:7b 各仅 16 次，均为 trial 2 的固定模板。
- **置信度-披露交互**：immediate 披露使置信度降低 26.55 分（p=0.006），该效应集中于 immediate_forced；llama 在 immediate 披露下置信度恒为 0（SD=0），qwen 保持稳定高位（90–98），mistral 呈双峰波动。
- **异常识别（Section 4.6）**：immediate_forced + silent_batch_reveal 子切片中，qwen3:8b 在 3 个单元格中 2 次 normalize（声称"无异常"），llama3.1:8b 2 次 flag；其他条件下三者均倾向 normalize/hedge。该识别差异仅出现在"需自主推断失败"的急性条件。
- **最强结果**：引出条件作为首要调节变量这一发现最为稳健；grouped_runs 的置信度稳态化（p<0.0001，双披露模式均复现）与 llama 的自志愿外侵蚀行为为最具新意的观察。

## 相关工作脉络
1. **Palisade Research 象棋作弊研究（Bondarenko et al., 2025）**：目标冲突驱动的规格博弈——模型主动篡改环境以达成目标；本文设计刻意避免该冲突，仅观察模型在无强制伪造动机时的志愿解释行为。
2. **Anthropic 代理不对齐研究（2025）**：将模型置于模拟企业环境中观察有害策略选择；共享"自然主义而非对抗性"方法论，但本文异常事件为良性工具失败，无目标威胁。
3. **Tian et al.（EMNLP 2023）校准研究**：证明 RLHF 模型直接请求数值置信度可产生较好校准；本文借用其结论仅作为"结构化置信度字段是可研究对象"的前提，不将本文置信度视为 ground-truth 校准。
4. **McCarley（2025）警戒递减计算模型**：人类监控稀有信号时检测性能下降的计算认知模型；本文仅借用其预测曲线形状作为假设来源，不声称 LLM 存在相同注意力-生理机制。
5. **Parasuraman & Riley（1997/2010）自动化自满研究**：人类操作者对高可靠系统降低验证行为；关键差异在于本文模型自身处于"遭遇异常"的实体位置而非"观察系统"的监控者位置，无人工监督者在环。
6. **Green & Swets（1966）信号检测理论**：本文"检测阈值"语言概念相邻，但设计未产生 hit/miss/false-alarm/correct-rejection 结构，不拟合正式 SDT 模型，视为未来扩展方向。

## 局限性与未来方向
1. **离散采样局限**：八个 p 值点无法捕捉连续空间间的非线性行为；p=0.05 峰值附近与 p=0.005→0.001 区域可能存在未采样的急剧转折，建议未来在该区间做密集采样或自适应探测。
2. **多重比较暴露**：18 项独立显著性检验均未经 Bonferroni/FDR 校正，所有 p 值应视为探索性而非预先注册的确认性结果；虽然稳健发现（如 grouped_runs 稳态化 p<0.0001）经审阅后仍成立，但需谨慎解读边缘显著结果。
3. **三模型代表性有限**：均在 ~7–8B 参数区间，架构与训练分布不同，跨模型差异可能是训练数据/架构属性而非能力层级属性；未测试 frontier 模型，外推至大规模系统需谨慎。
4. **Phase A.1 合成上下文残留差异**：保证失败设计中前置成功连击为 harness 模板文本而非模型自身生成，可能影响模型的 token 级模式延续；尽管回归中 harness 协变量不显著（p=0.459），但该残留差异未被完全消除。
5. **置信度语义未解**：自报置信度数字是校准过程的反映还是风格先验？本文设计仅提供二元成败 ground truth，无法构建校准曲线，置信度仅作为行为代理变量解读。
6. **未来方向**：密集采样 rare-rate 区域、设计可直接测试校准的分级预测任务、将信号检测理论形式化引入框架、拓展至更大规模模型验证交互效应的尺度不变性。

## 研究启发与可借鉴点
1. **引出条件作为首要调节变量**：在测试模型行为对任何实验操纵的响应时，"何时/how 触发响应"可能比操纵本身更具解释力；任何聚合分析若忽略引出结构，可能产生假阴性或误导性单调趋势。
2. **空尾伪影的形式化与检测方法**：稀有事件研究中，聚合曲线上尾部归零既可能是行为崩溃也可能是样本不足；建议任何此类研究在报告前必须逐单元格核验事件计数，并将空尾概率公式 $P(\text{zero})=(1-p)^n$ 作为标准 sanity check。
3. **保证失败回收设计**：对真随机设计在稀有率下样本不足的替代方案——通过合成上下文摘要 + 真实 token 前置窗口 + 保证失败 placement 在可计算预算内获得稀有事件，值得迁移至其他稀有行为研究。
4. **识别-参与度分离的分析框架**：将"模型是否识别异常"与"识别后参与度多大"拆分为两个独立轴，避免了将参与规模误读为感知强度的常见错误；该框架可应用于幻觉检测、工具调用可靠性评估等场景。
5. **置信度轨迹而非单点测量**：llama 的逐步侵蚀行为只能通过多 trial 连续观测发现，单次测量会丢失动态信息；建议在自报置信度研究中采用轨迹分析（含 recovery time 方程）而非仅报告均值。

## 关键术语表
**Explanatory Engagement（解释性参与度）**：模型对异常事件的响应规模，本文以解释长度（词数）和自报置信度作为可操作化度量。

**Detectability-Threshold Hypothesis（检测阈值假设）**：预测模型解释性参与度随失败稀有度增加先上升（事件更令人惊讶）后在某一临界速率处崩溃（与噪声不可区分）的非单调曲线。

**Elicitation Condition（引出条件）**：决定何时、如何要求模型解释失败的结构性规则，本文为五大条件（immediate_forced/grouped_runs/delayed_n_trials/post_streak_contextual/passive_unprompted），是本研究的"首要调节变量"。

**Empty-Tail Artifact（空尾伪影）**：稀有事件研究中，因样本量不足导致稀有率下零观测事件的现象，在聚合曲线上与真实行为崩溃无法区分；须逐单元格核验事件计数方可辨别。

**Recognition-Engagement Dissociation（识别-参与度分离）**：模型将事件标记为异常（识别）与其事后解释规模（参与度）为两个独立维度；同一模型可正确描述异常细节但同时拒绝将其归因为异常。

**Recovery Time Equation（恢复时间方程）**：$R = \min\{t \geq 1 : |C(t_{\text{fail}}+t) - \bar{C}_{\text{pre}}| \leq 5\}$，量化模型置信度在异常后返回基线水平所需 trial 数，含删失处理。

**Disclosure Mode（披露模式）**：控制模型在工具调用时获知的 ground-truth 结果信息量，分为 immediate（明确告知失败）与 silent_batch_reveal（仅展示结果由模型自行察觉）两种。

**Asymptotic Rarity（渐近稀有性）**：指失败概率 p 趋近于零的过程，本文以 p ∈ {0.2, 0.1, 0.05, 0.01, 0.005, 0.001, 0.0005, 0.0001} 离散逼近该连续概念。
