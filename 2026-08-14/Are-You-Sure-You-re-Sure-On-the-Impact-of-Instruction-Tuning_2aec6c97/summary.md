# 论文速读：Are You Sure You're Sure? On the Impact of Instruction Tuning on Confidence and Lexical Diversity

## 一句话总结
该研究通过配对评估三个基线模型与其指令微调变体，发现指令微调一致性地提升模型答案置信度（降低选择熵、提高口头报告置信度），但预测准确率并未同步改善；同时，指令微调对生成理由的词汇多样性产生异质性影响——跨理由多样性（1-SelfBLEU）一致下降，而表面词法多样性（Unique-2）则因模型和基准而异，且这些变化无法由答案选择差异或理由长度差异解释。

## 研究问题与动机
1. **现实需求**：大语言模型正被广泛应用于医学、金融、法律等高风险领域的问答与推理任务，这些场景要求模型提供可靠的置信度估计。
2. **已知现象**：指令微调等后训练方法已被证实会改变模型的置信度分布，并可能导致“过度自信”（verbalized overconfidence）。
3. **知识空白**：现有工作主要关注置信度或校准度，或单独研究生成文本的多样性，但**尚未有研究系统考察指令微调引起的置信度变化是否伴随着理由（rationale）词汇多样性的相应变化**。
4. **核心关切**：若模型变得更“确信”但更“缺乏多样性”，下游应用（尤其是依赖多次采样进行不确定性估计的场景）可能被误导。

## 核心贡献（创新点）
1. **系统性的配对评估**：首次在三组匹配的 Base/Instruct 模型族（Qwen2.5, Llama, Mistral）和三个推理基准（ARC-Easy, MMLU, CSQA）上，联合评估指令微调对置信度（选择熵、口头置信度）、校准度（ECE）及理由词汇多样性的影响。与以往仅关注单一维度的工作不同，本文提供了多维度变化的全景图景。
2. **受控的多样性分析实验**：创新性地设计了控制实验，限制 Base 和 Instruct 模型选择相同答案且理由长度匹配，从而将词汇多样性的变化从答案切换和生成长度差异中剥离出来，证实多样性变化是指令微调的独立效应。
3. **揭示置信度与多样性脱钩的发现**：明确证明指令微调带来的置信度提升**并不伴随**预测准确率的相应改善，也**不一致地**关联着词汇多样性或校准度的变化。这一发现挑战了“更自信意味着更一致/更确定”的简单假设，为后续不确定性估计工作提供了重要的反例依据。

## 方法详解
1. **模型置信度评估**：
   - **选择熵（Choice Entropy）**：将模型对每个候选答案的条件概率归一化后计算 Shannon 熵，值越高表示模型在候选答案间越不确定：
     $$H_{\mathrm{choice}}(x) = -\frac{\sum_{j=1}^{M} p_j \log p_j}{\log M}$$
     其中 $p_j$ 是答案 $y_j$ 的归一化概率。
   - **口头置信度（Verbalized Confidence）**：采用两阶段提示协议。第一阶段用最大似然确定答案；第二阶段提示模型直接输出一个 0–1 之间的数值，表示该答案正确的概率。

2. **词汇多样性评估**：
   - 对每个问题，使用零样本思维链（CoT）提示 `"Answer: Let's think step by step."` 采样 $K=5$ 条理由（temperature=0.7, nucleus sampling p=1.0, 最多100新token）。
   - **Unique-2**：统计理由中不同 bigram 的比例，值越大表明表面词汇越丰富。
   - **1-SelfBLEU**：计算每条理由与同问题其他理由的 BLEU 相似度的补集，值越大表明跨生成结果间的多样性越高。

3. **校准度评估**：
   - 使用期望校准误差（Expected Calibration Error, ECE），将预测按置信度分箱，计算每箱准确率与平均置信度的偏差加权求和。分别对基于似然（likelihood-based）和口头（verbalized）置信度计算 ECE。

4. **受控比较设计**：
   - 筛选出 Base 和 Instruct 模型**选择相同答案**的问题样本。
   - 在每组样本内，将两个模型的 rationale 数量对齐，并按 token 长度配对，截断至较短长度，再计算词汇多样性指标，从而隔离答案选择和生成长度带来的混杂效应。

## 实验与结果
1. **数据集与基线**：
   - 三个公开多选题基准：**ARC-Easy**（小学科学）、**MMLU**（多学科知识）、**CommonsenseQA**（常识推理）。
   - 三组 7B 量级配对模型：**Qwen2.5-7B** / **Qwen2.5-7B-Instruct**、**Llama-3.1-8B** / **Llama-3.1-8B-Instruct**、**Mistral-7B-v0.3** / **Mistral-7B-Instruct-v0.3**。所有模型和基准均公开可用。

2. **主要结果**：
   - **置信度普遍提升**：所有模型在所有基准上，选择熵显著下降，口头置信度显著上升。例如，Llama 在 ARC-Easy 上口头置信度从 49.2% 升至 90.4%，Mistral 在 CSQA 上选择熵从 0.736 降至 0.268。
   - **准确率变化不一致**：部分设置下准确率略有提升，部分无变化（如 Llama 在 ARC-Easy 上保持 82.2%），说明置信度提升并未带来可靠的性能增益。
   - **多样性变化异质**：
     - **1-SelfBLEU** 在所有模型和基准上**一致下降**（如 Mistral 在 ARC-Easy 上从 0.813 降至 0.626），表明跨理由的表面形式趋同。
     - **Unique-2** 变化方向不一致：Mistral 在 ARC-Easy/MMLU 上下降，但在 CSQA 上从 0.719 升至 0.750。
   - **受控实验结果**（表3）：在答案相同且理由长度匹配的条件下，1-SelfBLEU 仍然显著下降（Qwen -0.036, Mistral -0.069, Llama -0.012），而 Unique-2 变化因模型而异（Qwen 几乎不变，Mistral +0.050, Llama +0.053）。
   - **校准度与多样性脱钩**：变化模式复杂，例如 Qwen 在 ARC-Easy 上口头 ECE 下降但多样性也下降；Llama 在 MMLU 上两种 ECE 均上升而多样性下降。

3. **最强结果与提升**：口头置信度提升幅度最大（Llama 在 CSQA 上从 46.8% 升至 91.1%），但这是以选择熵下降和跨理由多样性下降为代价的，且准确率并未同步改善。

## 相关工作脉络
1. **校准度与置信度估计**（Jiang et al., 2021; Tian et al., 2023; Xiong et al., 2024）：本文与之关联在于使用了相同的选择熵和口头置信度度量，并进一步将校准度误差（ECE）纳入评估体系。
2. **后训练对置信度的影响**（Kadavath et al., 2022; Zhang et al., 2024; Huang et al., 2026）：前人发现 SFT/RLHF 会改变置信度分布，本文将其具体扩展到**词汇多样性**维度，指出置信度变化并非孤立现象。
3. **生成文本多样性评估**（Guo et al., 2025; Yun et al., 2025; Deshpande et al., 2025）：已有工作关注指令微调或采样策略对词汇、句法、语义多样性的影响，但本文首次将这些指标与**任务层面的置信度/校准度**联系起来。
4. **不确定性估计中的生成式方法**（Farquhar et al., 2024）：利用语义熵等方法检测幻觉，本文则从**词法层面**（Unique-2, SelfBLEU）补充了多样性分析视角。
5. **定位差异**：本文的核心差异在于**配对比较**（Base vs. Instruct）和**控制实验**，明确分离出指令微调对多样性的净效应，并揭示其与置信度变化的非一致性关联。

## 局限性与未来方向
1. **基准与语言局限**：仅使用三个英语多选题基准，未涵盖开放式生成、多语言或高风险专业领域（如医疗、法律的具体问答）。
2. **多样性度量局限**：仅评估了词法/表面层面（Unique-2, SelfBLEU），未涉及句法或语义多样性（后者可由 Semantic Entropy 等衡量）。
3. **未涉及安全敏感数据**：未评估指令微调在涉及不安全数据或人口统计属性问题上的输出行为。
4. **未来方向**（论文自述）：
   - 扩展至语义和句法多样性分析，覆盖更广泛的基准类型。
   - 验证跨语言的泛化性。
   - 研究后训练校准方法（如 adaptive temperature scaling）或解码干预对跨理由多样性的影响。
   - 探索减少过度自信是否会进一步压缩多样性，以及多样性-不确定性模式在语义层面的延伸。

## 研究启发与可借鉴点
1. **配对比较设计范式**：使用 Matched Base/Instruct 模型对进行控制实验，能有效剥离指令微调本身的效应，避免模型容量、参数规模等混淆因素。该方法可推广至研究任何后训练步骤的影响。
2. **受控多样性评估流程**：通过“相同答案+匹配理由长度”的条件筛选，将词汇多样性变化独立出来，为研究生成格式、采样策略对多样性的影响提供了可复用的实验模板。
3. **多维度联合评估框架**：同时考察置信度（熵、口头报告）、校准度（ECE）和多样性（Unique-2, SelfBLEU），避免了单一指标的片面结论，启示后续工作应在更多维度上交叉验证假设。
4. **实践警示**：在高风险应用中，仅凭口头置信度或选择熵判断模型可靠性存在风险，因为置信度提升可能伴随多样性降低（即模型越来越“千篇一律”地自信），需结合多次生成结果的变异性进行综合评估。
5. **可结合的创新机会**：可将本文的多样性度量与**语义熵**、**自一致性**等方法结合，构建更鲁棒的不确定性估计框架；也可研究如何在不损失校准度的前提下保持理由多样性，用于提升模型的可解释性。

## 关键术语表
- **Instruction Tuning（指令微调）**：在基座语言模型基础上，使用自然语言指令-响应对进行继续训练，使模型更好地遵循用户指令。
- **Choice Entropy（选择熵）**：衡量模型对多个候选答案的概率分布不确定性的信息论指标，熵越低表示模型越倾向于某个答案。
- **Verbalized Confidence（口头置信度）**：通过提示让模型直接输出一个数值概率，反映其对自身选定答案的主观确信程度。
- **Lexical Diversity（词汇多样性）**：衡量生成文本中词汇使用的丰富程度，常用 Unique n-gram 比例或 Self-BLEU 等指标评估。
- **Self-BLEU**：计算同一组生成结果内部两两之间的 BLEU 相似度，用于衡量生成内容的重复性或多样性。
- **Expected Calibration Error (ECE)**：评估模型预测置信度与实际操作准确率之间一致性的指标，值越低表示校准越好。
- **Rationale（理由/论证）**：模型在给出最终答案前生成的中间推理步骤文本，通常通过 CoT 提示获得。
- **Paired Evaluation（配对评估）**：对同一模型的不同版本（如 Base 与 Instruct）在相同数据上进行对比，以控制模型架构等因素的干扰。
