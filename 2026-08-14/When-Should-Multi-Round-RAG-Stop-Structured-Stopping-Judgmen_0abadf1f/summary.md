# 论文速读：When-Should-Multi-Round-RAG-Stop-Structured-Stopping-Judgmen

## 一句话总结
本文针对多轮检索增强生成（RAG）中的停止决策问题，将 S2G-RAG 的结构化充分性与缺口判断机制适配到冻结的 Search-R1 推理管道中，训练了一个 Qwen3.5-2B 停止裁判模型；在 HotpotQA 确认性测试集上，该策略使检索调用减少 3.70%（77 次），答案精确率（EM）仅下降 0.625 个百分点，控制在预设的 2 个百分点容忍范围内。

## 研究问题与动机
1. **多轮 RAG 的停止困境**：检索不足会导致答案缺乏证据支持，而检索过度则消耗延迟与计算资源，且额外上下文可能将正确答案变为错误答案。
2. **序列选择与状态分类的本质差异**：已部署的停止策略由轨迹上第一个 STOP 决定，而非独立状态分类任务；一个早期误判会抑制后续所有状态，现有状态级评估无法直接反映在线策略行为。
3. **结构化判别的价值尚未在 Search-R1 上验证**：S2G-RAG 提出同时预测充分性与缺失信息，但其在不同上游系统（如 Search-R1）上的迁移效果未知，SIM-RAG 等二元裁判在跨系统迁移时出现有害改变。
4. **检索降本与质量保持的权衡边界不清**：现有工作未明确回答"在冻结推理器、检索器、语料库的前提下，仅调整停止时间能带来多大质量-成本优化空间"。

## 核心贡献（创新点）
1. **将 S2G 结构化裁判适配到 Search-R1 管道**：训练 Qwen3.5-2B judge 输出 JSON 格式的 `sufficient` 布尔字段与 `gap_items` 缺失列表，与已有 Search-R1 研究仅改进推理器或检索器的本质不同。
2. **提出轨迹感知的分层评估框架**：将评估拆分为候选可达性审计、状态排名诊断、最早阈值穿越策略、答案质量与成本四个独立层次，区别于仅报告端到端 EM 的既有工作。
3. **揭示状态排名与在线策略的行为错配**：证明二元 LoRA 可提升 STOP AP（0.732→0.828），但在 deployed 阈值下反而导致 EM 从 36.5% 降至 31.5%，结构化 S2G 目标可将错误 STOP 从 99 降至 24。
4. **提供确认性非劣效性实验证据**：在预声明的 −2 个百分点 EM 容忍边界内，实证检索调用减少 3.70%（95% CI 不包含零），但明确指出未建立安全停止或总推理成本降低。

## 方法详解
1. **可达状态与 Stop-Now 答案定义**：对问题 $q_i$，Search-R1 产生轨迹状态 $z_{i,t} = (q_i, C_{i,t}, h_{i,t}, a_{i,t}^{\text{native}})$，其中 $C_{i,t}$ 为累积检索上下文；冻结答案探测函数 $g$ 输出 $\tilde{a}_{i,t} = g(q_i, C_{i,t})$，若 $\tilde{a}_{i,t}$ 与官方答案匹配且原生策略提议 SEARCH，则存在安全早停机会。
2. **条件预言诊断**：质量预言（quality oracle）选取最早可达正确探测答案，EM 为 51.5%（+5.0pp）；成本预言（cost oracle）仅对原生已答对问题提前停止，可移除 25.05% 检索调用且保持原生 EM 固定。
3. **结构化裁判训练**：Qwen3.5-2B 以 3  epoch（12,654 步）学习输出 `sufficient` 后跟 `gap_items` 的 JSON  Schema；使用分组验证集的 teacher-target token NLL 选择 Epoch 1，不依赖最终答案标签。
4. **阈值冻结与非劣效性检验**：分组验证选择满足 STOP 精确率 ≥0.90 且预测 STOP 状态 ≥10 的最大召回阈值；确认性检验要求 $\Delta_{\text{EM}}$ 的 95% CI 下限 >−0.02 且 $\Delta_{\text{search}}$ 的 95% CI 上限 <0。
5. **损失函数与校准**：所有训练损失有限，无 OOM；扩展 S2G 的 Brier 分数 0.2952、ECE 0.2911，校准弱于 Structured Base（0.1992/0.1179），表明排名改进与置信度校准存在 gap。

## 实验与结果
1. **数据集与基线**：HotpotQA distractor 开发集前 1,000 题（索引 200–999 为确认性测试集）；上游为 Search-R1 Qwen2.5-7B PPO v0.2 + E5 top-3 检索 + Wiki-2018 语料 + 最多 4 次搜索；对比 Structured Base、Old S2G LoRA、Expanded S2G LoRA。
2. **探索性可达性审计（H0，200 题）**：523 个原生 SEARCH 中有 143 个（27.3%）发生在探测已得正确答案的状态；70 题存在成本优化空间，10 题存在有害过度检索；质量预言 EM 51.5%，成本预言可移除 131/523 检索（25.05%）。
3. **确认性测试结果**：Native EM 0.44875、平均搜索 2.60125；Expanded S2G EM 0.44250、平均搜索 2.50500；$\Delta_{\text{EM}} = -0.00625$（95% CI [−0.01250, 0]），$\Delta_{\text{search}} = -0.09625$（95% CI [−0.12000, −0.07375]）；检索减少 77 次（3.70%）。
4. **状态诊断**：Expanded S2G STOP AP 0.40358，较 Structured Base（0.36375）提升 0.03983（95% CI [0.00571, 0.07228]）；69 次系统级早停中 42 次安全、27 次不安全（不安全率 39.13%）。
5. **最强结果**：检索调用减少 3.70% 且 EM 损失在预设容忍范围内通过非劣效性检验；但准确率未提升，安全停止未建立。

## 相关工作脉络
1. **IRCoT [1]**： interleaving 检索与思维链推理，本文与其区别在于不改进推理器，仅干预停止决策。
2. **Self-RAG [2]**：学习检索与反思决策，本文借鉴其控制 token 思路但采用外部 judge 而非自生成。
3. **Adaptive-RAG [3]**：按问题复杂度路由检索策略，本文定位在单策略内部的停止优化而非多策略路由。
4. **Search-R1 [4]**：RL 训练 LLM 使用搜索引擎，本文以其为冻结上游系统，仅添加外部停止裁判。
5. **SIM-RAG [5]**：学习何时继续搜索，本文发现其跨系统迁移到 Search-R1 时产生 8 次有害改变、0 次挽救。
6. **S2G-RAG [6]**：结构化充分性与缺口判断，本文将其 adapt 到 Search-R1 状态接口并训练专用 judge。
7. **TASR [7] / RAG-Critic [8]**：免训练停止与 critic 反馈工作，本文强调需联合报告状态排名、最早穿越策略与系统级风险。

## 局限性与未来方向
1. **安全停止未建立**：69 次早停中 39.13% 不安全，验证集 0.90 精确率约束未转移到测试集。
2. **总推理成本未归一化**：judge 推理的计算、延迟、能耗未折算为检索等价单位，仅报告检索调用次数。
3. **校准差距**：Expanded S2G 的 ECE（0.2911）显著高于 Structured Base（0.1179），排名改进未伴随置信度校准。
4. **可推广性边界**：结论依赖冻结的 Search-R1 7B/E5/Wiki-2018/top-3/four-search 配置，不同上游系统的条件预言可达性不同。
5. **未来方向**：校准感知训练、轨迹级损失惩罚首次不安全穿越、显式成本敏感目标、匹配延迟/能量的效率评估。

## 研究启发与可借鉴点
1. **分层评估设计可迁移**：将"可达性审计→状态排名→最早穿越策略→系统质量成本"四层次分解用于其他停止/路由研究，避免单一端到端指标的误导。
2. **结构化监督缓解过度停止**：S2G 的 gap_items 监督显著降低错误 STOP 决策（99→24），提示多标签结构化输出比二元分类更适合停止裁判训练。
3. **非劣效性检验框架**：预声明容忍边界（−2pp EM）配合配对 bootstrap CI，为"降本不降质"类研究提供可复用的统计报告范式。
4. **探索性/验证性/确认性数据分离**：明确区分 H0 探索集、分组验证集、索引 200–999 确认集，防止数据泄露与选择性报告。
5. **与团队方向结合机会**：若团队研究低资源 RAG 或边缘部署，可借鉴其"冻结上游+训练轻量 judge"范式，用更小模型（如 1B）在特定领域做停止策略适配。

## 关键术语表
**Multi-round RAG**：多轮检索增强生成，语言模型在推理过程中反复调用检索器获取证据的架构。
**Stopping policy**：停止策略，决定何时终止检索循环、基于当前上下文生成答案的决策规则。
**S2G（Sufficiency-and-Gap）**：充分性与缺口判断，结构化裁判同时输出"证据是否充分"与"还需哪些信息"。
**Reachable state**：可达状态，搜索轨迹中检索器成功返回文档后的中间状态。
**Conditional oracle**：条件预言，利用生成后标签评估的理论上界（质量预言/成本预言），不可部署但用于诊断。
**Non-inferiority margin**：非劣效性边界，预设的质量损失容忍范围（本文取 −2 个百分点 EM）。
**Early-stop safety**：早停安全性，第一次阈值穿越对应的停止决策是否为安全机会（探测答案正确且原生策略本应继续搜索）。
**STOP precision/recall/AP**：停止精确率/召回率/平均精度，分别在阈值穿越决策、状态排序、状态级二元分类上的评估指标。
