# 论文速读：DSPrompt: Dynamic Soft Prompt Defense Against M-RAG Corruption

## 一句话总结
论文提出 **DSPrompt**，一种动态软提示防御框架，通过在冻结的多模态检索器（如CLIP）各层插入轻量级可学习提示，并采用动态 min-max 对抗训练，直接重塑检索器的嵌入语义，将中毒文档的相似度压低至 top-k 之外，同时保持良性检索质量。该方法无需额外查询时检测器或重排序开销，相对骨干仅增加 <1% 参数。

## 研究问题与动机
1. **核心问题**：多模态检索增强生成（M-RAG）系统易受对抗性嵌入中毒攻击，恶意构造的图文对可在共享向量空间中与良性条目相似，误导检索并诱发有害输出。
2. **现有方法局限一**：当前防御（如 RoCLIP、IRAG）主要在查询时运行，依赖辅助检测器或图像-文本一致性检查进行重排序，推理开销随查询量和库规模增长。
3. **现有方法局限二**：现有防御通常针对固定的攻击分布设计，在开放部署中对新扰动或未见攻击策略泛化能力差。
4. **研究动机**：能否以更小代价，直接重塑检索器本身的嵌入语义来缓解中毒，而非在输出端筛选？

## 核心贡献（创新点）
1. **提出将RAG防御视为检索器语义重塑问题**：与基于查询时后处理（检测/重排）的防御本质不同，DSPrompt 离线训练一次轻量软提示，部署时直接替换编码器，无需额外模块或每查询优化。
2. **设计动态对抗提示学习方案**：与静态对抗训练或固定毒样本不同，该方案在训练每一步在线生成“最难”的对抗毒化文档（PGD攻击+最优恶意文本选择），使防御能泛化到未见攻击策略。
3. **引入浅至深（Shallow-to-Deep）提示容量调度**：与均匀插入提示不同，该设计将更多提示令牌分配给负责跨模态对齐的深层网络，以更少的总参数量实现更精准的语义修正。
4. **设计联合损失函数保持选择性**：通过 InfoNCE 对比损失压制中毒得分，同时引入清洁锚点正则化（Clean Anchor Regularization）约束嵌入漂移，确保良性检索质量和生成保真度几乎无损。
5. **极低成本高效部署**：仅向冻结的双编码器插入少量提示，添加参数 <1%，推理时文档可预先嵌入和索引，查询时无额外计算开销，整体比现有防御（如RoCLIP）快约1.7倍。

## 方法详解
1.  **软提示架构（Prompt Architecture）**：在视觉和文本编码器的每个 Transformer 层（共 L 层）的 `[CLS]` 标记后插入 `m_l` 个可学习提示令牌 `P^(l)`。提示令牌参与该层的自注意力交互后，在传递到下一层前被移除，从而在不改变骨干序列长度和结构的前提下注入修正信号。
2.  **浅至深提示长度调度（Multi-scale Prompt-length Schedule）**：根据公式 `m_l = r^(ceil(3l/L) - 1)` 分配提示长度（r为增长因子）。将层划分为浅、中、深三组，提示数量呈几何增长。深层网络负责跨模态对齐，对抗扰动的影响主要在深层显现，因此将更多容量分配给深层可精准修正对齐，而浅层稀疏分配避免扰动依赖良性特征表示的浅层表示。
3.  **防御损失函数（Defense Loss Functions）**：训练损失由三部分组成：
    *   **对比检索损失 (`L_q->d`)**：使用 InfoNCE 损失，将查询与其清洁正样本拉近，与负样本（其他查询的正样本及在线生成的对抗毒样本）推远。
    *   **对称损失 (`L_d->q`)**：将文档作为锚点、查询作为正样本的对称 InfoNCE 损失，用于抑制重塑空间中的“中心性（hubness）”问题。
    *   **清洁锚点正则化 (`L_anc`)**：约束被提示修改后的编码表示 (`Phi_theta`) 与原始冻结编码表示 (`Phi_0`) 之间的 L2 距离，防止良性嵌入偏离原有分布，保护检索效用。
4.  **动态 Min-Max 训练（Dynamic Min-Max Training）**：
    *   **内循环（攻击者/最大化）**：对于每个查询-正样本对，首先通过无梯度搜索从候选池中选择能使当前防御检索分数最大化的恶意文本 `T^-`（结合查询文本、诱导目标答案和误导性图片描述）。然后，在固定的 `T^-` 下，使用 PGD 攻击优化图像扰动 `delta`，生成强对抗毒文档 `d_tilde`。
    *   **外循环（防御者/最小化）**：使用上述内循环生成的毒样本，结合清洁正样本，计算总防御损失 `L(theta)`，更新软提示参数 `theta`。训练使用独立数据集，确保评估时从未见过相同的对抗样本。
5.  **部署**：训练完成后，优化后的提示参数 `theta*` 被固定在编码器中。推理时，文档嵌入通过标准近邻搜索完成，无需重排或额外计算。

## 实验与结果
*   **数据集与基准**：在四个基准上进行评估：**Places365**, **ImageNet**, **WebQA**, **InfoSeek**。对抗三种攻击：**PE-C** (类目标攻击), **GPA** (全局攻击), **Clean-L** (清洁标签攻击)。
*   **评估指标**：安全性指标：中毒检索率 PRR@k (↓), 攻击成功率 ASR (↓)；效用指标：语义效用保真度 SUF@3 (↑), 任务保真度 TF (↑)。
*   **主要结果**：
    *   **Places365 (PE-C)**: DSPrompt 将 PRR@1 从 82.30% 降至 **6.71%**，ASR 从 81.15% 降至 **6.66%**，同时保持 SUF@3 ≈ 98.84%, TF = 93.18%。远超 RoCLIP（ASR 26.03%）。
    *   **ImageNet (PE-C)**: PRR@1 降至 **4.40%**，ASR 降至 **4.40%**，TF 高达 95.40%。
    *   **WebQA (GPA, 未见攻击)**: ASR 降至 **0.64%**，TF 达 80.21%，证明对未见攻击的泛化能力。
    *   **InfoSeek (Clean-L, 未见攻击)**: ASR 降至 **12.00%**，TF 保持 70%。
*   **效率**：相比无防御（1.0x）和 RoCLIP（3.08x），DSPrompt 的查询平均运行时间开销为 **1.85x**，且增加参数 <1%。
*   **结论**：DSPrompt 在显著降低中毒检索率和攻击成功率的同时，保持了接近无防御系统的检索质量和生成保真度，且在三个攻击家族（包括两个未见攻击）上均有效，展现出良好的安全性和泛化性权衡。

## 相关工作脉络
1.  **RoCLIP (Yang et al., 2023)**：一种在预训练阶段鲁棒训练的 CLIP 变体，可通过重新关联图像和一致文本来重排序检索候选。本文与之相比，优势在于无需预训练控制，离线训练提示后即可直接应用于冻结的现有检索器，且无查询时重排序开销。
2.  **IRAG (Luo et al., 2026)**：结合图像判别和显式匹配进行危害分离的防御。本文与之相比，不依赖每个查询的多重冗余参考，方法更轻量，且不修改检索流水线。
3.  **PoisonedEye-C / PE-C (Zhang et al., 2025)**：本文评估的主要攻击之一，通过类目标嵌入中心偏移进行攻击。DSPrompt 的目标正是防御此类及类似攻击。
4.  **MM-PoisonRAG / GPA (Ha et al., 2025)**：全局中毒攻击，使单个毒化条目能被大量查询检索。本文展示了 DSPrompt 对此类未见攻击的防御能力。
5.  **Poisoned-MRAG / Clean-L (Liu et al., 2025)**：清洁标签中毒攻击，保持图像-文本一致性同时提升检索性。本文证明了防御对这类攻击的有效性。
6.  **Text-only RAG 防御 (如 BadRAG, Certifiable Robustness)**：主要针对纯文本检索器的防御。本文明确指出这些方法扩展到包含连续图像扰动的多模态场景存在困难，而 DSPrompt 原生设计用于多模态编码器。

## 局限性与未来方向
*   **局限性**：
    1.  在线对抗样本生成（内循环的文本选择和PGD）在训练阶段增加了计算复杂度。
    2.  当前调度策略和损失权重（如 λ_sym, λ_anc, τ）可能需要针对特定数据集或编码器进行一定调整。
    3.  论文主要评估了针对嵌入空间的对抗性中毒攻击，对于其他类型的攻击（如针对生成阶段的攻击）效果未验证。
*   **未来方向**（合理推断）：
    1.  探索更自适应的提示分配策略，而非固定的浅至深调度。
    2.  将防御思想扩展到其他多模态检索或生成任务。
    3.  研究如何进一步减少在线攻击生成的计算开销。
    4.  评估防御在更多样化的攻击场景和更复杂的真实世界部署下的表现。

## 研究启发与可借鉴点
1.  **防御思路转换**：将防御重点从“查询后检测/过滤”转向“训练时重塑检索器内部语义表示”，为设计更高效、更泛化的 RAG 安全防御提供了新范式。
2.  **动态对抗训练设计**：内循环结合文本选择（离散优化）和图像扰动（连续优化）的 min-max 博弈框架，能有效提升防御对未知攻击的泛化能力，此思路可迁移至其他对抗训练场景。
3.  **分层提示调度**：“浅至深”的容量分配策略，基于对模型各层功能（浅层特征提取 vs 深层语义对齐）的理解，以极少参数实现高效修正，对提示工程和多模态模型适配具有启发意义。
4.  **效用保护机制**：清洁锚点正则化（`L_anc`）直接约束嵌入空间的漂移，在提升鲁棒性的同时保障下游任务性能，是平衡安全与效用的有效技巧。
5.  **实验设计借鉴**：采用独立训练数据、测试时 unseen 攻击（GPA, Clean-L）来验证泛化性，以及同时评估安全性（PRR, ASR）和效用（SUF, TF）的多维指标体系，为防御类研究提供了规范的评估范例。

## 关键术语表
**M-RAG (Multimodal Retrieval-Augmented Generation)**：多模态检索增强生成，利用多模态检索器从知识库中检索图文对，辅助大视觉语言模型（LVLM）生成答案的系统。
**DSPrompt (Dynamic Soft Prompt)**：本文提出的动态软提示防御框架，通过在编码器层插入可学习提示对抗中毒攻击。
**Soft Prompt Tuning**：在预训练模型（如Transformer）的输入或中间层插入少量可学习令牌（prompt tokens），微调这些令牌以适应特定任务，而保持骨干网络参数冻结的方法。
**PRR@k (Poisoned Retrieval Rate)**：中毒检索率，top-k 检索结果中包含至少一个中毒文档的查询比例。
**ASR (Attack Success Rate)**：攻击成功率，最终生成答案命中攻击者预设目标答案的查询比例。
**SUF@k (Semantic Utility Fidelity)**：语义效用保真度，衡量防御后检索结果的语义相关性相对于原始（无防御）检索结果的保持程度。
**TF (Task Fidelity)**：任务保真度，防御后模型生成的答案与干净（无中毒）基准答案匹配的比例。
**Min-Max Training**：一种对抗训练范式，内循环（max）寻找对当前模型最有利的对抗样本，外循环（min）更新模型参数以最小化在这些样本上的损失。
