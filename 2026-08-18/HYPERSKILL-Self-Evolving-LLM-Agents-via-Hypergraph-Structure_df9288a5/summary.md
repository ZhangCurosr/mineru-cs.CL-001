# 论文速读：HYPERSKILL-Self-Evolving-LLM-Agents-via-Hypergraph-Structure

## 一句话总结
论文提出 HYPERSKILL，一种基于超图的经验记忆框架，将 LLM agent 的历史轨迹建模为连接子任务节点与可复用技能节点的超边，通过双路检索与结构感知的定期维护实现记忆的自进化，在 xBench、GAIA 和 WebWalkerQA 上显著优于 10 种基线。

## 研究问题与动机
- 现有经验记忆系统在“存什么、如何结构化与检索、如何演进”三个维度相互割裂，仅存储孤立条目，丢弃了子任务与技能间的组合关系。
- 检索机制多依赖平面向量相似度，无法表征技能与子任务模式之间的 n-ary 共现关系。
- 记忆演进多为无条件累积或单点剪枝/去重，未利用拓扑结构联合质量信号进行清洗与合并。
- 轨迹本质是包含子任务、技能与结果的多项关联，扁平列表或二元图会损失完整的组合上下文，制约跨任务经验迁移。

## 核心贡献（创新点）
- 提出超图经验记忆架构：将记忆表示为子任务节点与技能节点构成的超图，每条超边绑定单一轨迹的组合上下文与蒸馏教训。与已有工作本质区别在于：现有系统或存原始轨迹、或抽象为独立技能/工作流，均未建模子任务与技能在同一轨迹中的多项联合关系。
- 设计双路检索机制：子任务路径通过查询分解匹配历史步骤以捕获程序相似轨迹，轨迹路径直接匹配超边表征以覆盖高层语义，二者融合互补。与已有工作本质区别在于：现有方法仅依赖全任务描述的单一语义检索，无法召回“表面措辞不同但程序结构一致”的相关经验。
- 基于共现频率的技能排序：利用技能节点跨轨迹复用且去重的特性，按检索结果中的共现次数 $\kappa(v)$ 排序，引入结构信号而非单纯语义相似度。与已有工作本质区别在于：传统向量检索只能判断技能描述是否与当前任务“看起来相似”，而共现信号直接反映该技能在历史相关轨迹中“被反复验证有效”的强度。
- 结构感知记忆演进：定期执行质量驱动剪枝与基于质量加权传播的冗余技能合并，联合考虑节点效用分数与超图拓扑，保持记忆紧凑高质量。与已有工作本质区别在于：多数基线仅做单点去重或轻量剪枝，本文首次将节点效用嵌入邻接矩阵并结合图传播，实现拓扑感知的结构化知识压缩。

## 方法详解
- **节点与超边定义**：节点 $v_i=(c_i, \ell_i, \gamma_i)$ 分为子任务节点 $\mathcal{V}_u$（记录步骤描述与前置条件）和技能节点 $\mathcal{V}_s$（记录可复用策略/错误模式）；$\gamma_i$ 为动态效用分，由历史检索成功率与平均步骤效率加权计算。每条超边 $e_j=(V_j, d_j, \ell_j, \gamma_j)$ 对应一个完整轨迹，$V_j$ 包含该轨迹提取的子任务与技能节点集合，$\ell_j$ 为蒸馏教训，超边嵌入为 $\mathbf{h}_e=\phi(d_j\| \ell_j)$。
- **双路检索**：收到新任务 $d_q$ 后，LLM 将其分解为子任务序列 $\mathcal{P}_0$，编码后检索 top-$k_u$ 最相似子任务节点，通过关联超边扩展得到候选轨迹集 $\mathcal{E}_{\text{sub}}$；同时直接将任务描述编码为 $\mathbf{h}_{d_q}$ 检索 top-$k_e$ 最相似超边得 $\mathcal{E}_{\text{traj}}$，两者取并集 $\mathcal{E}^*$。
- **共现技能排序**：从 $\mathcal{E}^*$ 中收集所有候选技能节点 $R_s$，统计每个技能在检索到的超边中出现的次数 $\kappa(v)$，按 $\kappa$ 降序取 top-$k_s$ 作为执行引导，平局时按语义相似度破 tie。
- **记忆更新与去重**：任务完成后通过 outcome-conditioned prompt 提取新技能与教训，新生技能嵌入与现有节点相似度超过阈值 $\delta_{\text{dedup}}$ 则合并，否则新建节点；最终将新超边加入超图，并重算参与检索元素的 $\gamma$。
- **周期性维护**：每 $N_{\text{maint}}$ 轮触发。剪枝：移除检索足够频繁（$\nu(v)\ge N_{\min}$）但效用分低于阈值（$\gamma(v)<\tau_{\text{prune}}$）的节点。合并：构建质量加权共现矩阵 $\mathbf{W}$（边权重为 $\min(\gamma_i,\gamma_j)\cdot \sum 1/|V_e|$），经 L 步对称传播生成结构嵌入 $\tilde{\mathbf{Z}}$，相似度超 $\delta_{\text{merge}}$ 的技能对由 LLM 合并为更高层技能，保留超边隶属关系。

## 实验与结果
- **数据集与基线**：xBench、GAIA、WebWalkerQA 三个代理基准；对比 ReasoningBank、ExpeL、AWM、Generative、Voyager、DILU、Cheatsheet、MemP、MemEvolve、PlugMem 及 No Memory，共 11 组；骨干模型为 GPT-4o 与 Qwen3-30B-A3B。
- **主要结果**：HYPERSKILL 在几乎所有基准-模型组合上取得最高成功率。GPT-4o 下较次优方法提升 +3.00 (xBench)、+2.30 (GAIA)、+0.59 (WebWalkerQA)；Qwen3-30B
