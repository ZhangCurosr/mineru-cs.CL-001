# 论文速读：Computational KJ-Hō: An Analyst-Bias-Free Insight Extraction Framework from Large-Scale Qualitative Data Using Domain-Specialized LLMs

## 一句话总结
本文提出 Computational KJ-Hō 理论框架，将日本 KJ 法、扎根理论与皮尔士溯因推理融合，并依托面向营销研究领域的专用 LLM（经 CPT+SFT 两阶段训练），实现大规模消费者定性数据中“分析师偏见可消除”的洞察自动提取与营销策略生成。

## 研究问题与动机
- **认知容量瓶颈**：传统定性研究（KJ 法、扎根理论、主题分析）受限于人类分析师的工作记忆，实际可处理的优质数据单元仅约 100–200 条，难以应对数字触点带来的海量、异质消费者文本。
- **分析师偏见与复现危机**：社会行为科学大规模复现研究显示，同一数据经不同分析师处理后完全一致率仅约 34%，增加分析师数量反而会放大偏见而非消除。
- **现有 LLM 自动化系统的五大缺陷**：(1) 依赖通用 LLM，缺乏领域知识内化（CPT）；(2) 局限于单一语料库分析，无法捕捉跨访谈段落的隐性模式；(3) 缺乏针对“消费者洞察提取”任务的领域评估指标；(4) 分析输出止于编码本/主题结构，未链接至可执行商业策略；(5) 锚定西方（WEIRD）研究传统，忽视非西方方法论。
- **行业战略需求**：成熟市场中消费者需求快速分化，营销研究亟需在更大数据规模上保持洞察深度与战略可转化性，现有通用 AI 工具无法填补该 gap。

## 核心贡献（创新点）
- **跨三大思想传统的理论框架**：将 KJ 法（数据涌现式整合）、扎根理论（自下而上理论构建）与溯因推理（生成最合理解释）统一于“数据驱动解释生成”认识论，区别于以往纯工程导向的自动化管线。
- **三层架构与 CPT 领域嵌入重塑**：设计数据摄取→洞察提取→策略生成的三层架构，核心技术突破在于通过 CPT 直接改造嵌入空间，使模型能区分通用 LLM 混淆的细粒度语义（如“高价”vs“高级感”）。
- **两项领域定制评估指标**：提出 InsightExtraction-F1 与 MarketingQA，前者量化系统洞察与专家金标准的匹配度，后者评测领域知识内化程度，弥补现有 NLP 指标仅测量表面文本相似度的不足。
- **直面 AI 定性研究中的 WEIRD 问题**：首次将起源于日本的 KJ 法置于计算框架核心，将文化效度作为设计前提，挑战英语/西方中心的研究范式。
- **实践驱动的问题建模**：基于作者近 30 年全球营销研究经验提炼 5 项实践约束并转化为系统设计需求，填补了现有 LLM 定性研究缺乏实战约束输入的空缺。

## 方法详解
- **三层计算架构**：
  1. **数据摄取与结构化层**：对访谈转录、在线评论等原始文本进行说话者属性提取、意图/情感/行为动机解析，按语义块切分为原子数据单元，并映射至领域嵌入空间。
  2. **消费者洞察提取层（核心）**：计算复现 KJ 法“标签分组→拟定标题→空间排布”流程。① 基于 CPT 领域嵌入进行自下而上语义聚类，同步交叉受访者属性检测段落差异；② SFT 模型为每个簇生成自然语言洞察（Heading）并显式链接原始证据；③ 挖掘簇间因果/对立/层级关系，输出可探索的结构化地图。
  3. **策略生成层**：将结构化洞察转化为可执行战术，包括目标客群定义、品牌机会点、沟通信息与创意提案，以及自动分析报告。
- **两阶段训练策略**：
  - **CPT**：在六大类营销研究语料（消费者心理学报告、商业/法律文献、学术论著、研究方法、营销实践智慧、企业史含破产案例）上继续预训练，重塑嵌入空间。
  - **SFT**：在专家互审的配对数据（消费者文本 → 营销洞察 → 营销策略）上微调，确保领域知识内化先于任务适配；每份样本需至少两位独立专家交叉审核以稀释个体偏见。
- **Human-on-the-loop 分工**：人类仅介入“设定分析目标”与“评估输出/决策”两个环节，模式识别与分类任务完全由模型自主完成，保障早期分析不受先验假设干扰。
- **部署规模**：设想 17B–27B 参数本地部署模型，兼顾复杂推理能力、数据主权与边际成本优势。
