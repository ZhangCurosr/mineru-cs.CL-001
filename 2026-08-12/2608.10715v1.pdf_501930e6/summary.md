# 论文速读：MOST BIOMEDICAL PUBLICATIONS SHOW SIGNS OF LLM-ASSISTED WRITING

## 一句话总结
本文提出一种基于词汇频率变化的无偏估计方法，用于量化学术论文中 LLM 辅助写作的比例，并将其应用于 PubMed Central (PMC) 开放获取生物医学期刊全文；结果显示到 2025 年底，89% 的论文显示出 LLM 辅助写作迹象。

## 研究问题与动机
- **核心问题**：LLM 在学术写作中的普及程度如何？现有方法仅能提供下限估计，缺乏可靠的全局度量手段。
- **现有方法不足**：基于词频缺口（frequency gap）的方法（如 Kobak et al., 2025）只能给出 LLM 使用量的下界；基于混合模型的方法结果高度依赖生成文本所用的 prompt 和模型选择。
- **政策需求**：需要准确的 LLM 使用率估计以指导学术出版政策制定。
- **细粒度分析缺失**：此前研究缺乏按论文章节（Methods、Results、Discussion 等）细分 LLM 使用情况的系统分析。

## 核心贡献（创新点）
- **提出无偏估计框架**：基于预定义的 LLM 关联标记词集合，通过线性外推构建反事实的人类写作基线频率，从而估算 LLM 使用比例，突破了以往仅能给出下界的方法限制。
- **章节级细粒度分析**：首次将 LLM 使用估计扩展到论文各章节（Abstract、Methods、Results、Discussion），揭示不同部分的 LLM 使用差异——Discussion 使用率（68%）约为 Methods（32%）的两倍。
- **大规模实证发现**：到 2025 年底，PMC 全文 89% 的论文显示出 LLM 辅助写作迹象，显著高于此前文献报告的所有估计值。
- **严谨的模拟验证**：通过含已知真实值的模拟实验（100,000 篇/年，500 个标记词），验证估计方法可高精度还原真实 β 值（|β̂ − β| < 0.02）。
- **跨国比较与语言趋同证据**：发现母语为英语国家 LLM 使用率（37%）显著低于非母语国家（72%），且两者在 2025 年的标记词频率已趋近，揭示了 LLM 驱动的语言同质化现象。

## 方法详解
- **标记词选取**：沿用先前工作（Kobak et al., 2025）识别的 379 个 LLM 关联标记词（如 "these"、"potential"、"delves"），这些为可在任何研究语境中使用的非内容词。
- **频率建模**：对每个标记词，计算其在时间 t 的使用频率 q(t)（含该词至少一次的文档占比）。基于 2018–2022 年（ChatGPT 发布前）的月度数据拟合线性回归，外推得到反事实人类写作频率估计 $\hat{p}_{\mathrm{human}}(t)$。
- **频率缺口与下界**：单词的频率缺口 $\Delta = q - \hat{p}_{\mathrm{human}}$ 给出 LLM 使用比例的下界。更强的下界公式为：
$$\hat{\beta}_{\mathrm{LB}} = \frac{q - \hat{p}_{\mathrm{human}}}{1 - \hat{p}_{\mathrm{human}}} \geq \Delta$$
推导基于混合模型 $q = (1-\beta)p_{\mathrm{human}} + \beta p_{\mathrm{LLM}}$，并取 $p_{\mathrm{LLM}} \leq 1$ 的上界。
- **阈值优化**：将标记词按频率排序，选取频率低于阈值 T 的词构成集合 G(T)，在 19 个阈值网格中搜索使 $\hat{\beta}_{\mathrm{LB}}$ 最大化的 T（同时排除标准误差 > 0.025 或 $\hat{p}_{\mathrm{human}} \geq 0.999$ 的阈值），最终估计为 $\hat{\beta} = \max_T(\hat{\beta}_{\mathrm{LB}})$。
- **误差传播**：q 的方差服从二项分布 $\mathrm{Var}[q] = q(1-q)/n$；$\hat{p}_{\mathrm{human}}$ 的方差通过回归外推公式计算；$\hat{\beta}$ 的方差通过 Delta 方法传播合并。
- **裁剪分析**：为公平比较不同长度章节，从各章节中随机抽取 255 词片段（对应摘要中位长度）进行估算。
- **模拟验证**：假设 n=100,000 文档/年、m=500 标记词，对 $p_{\mathrm{human}}$ 采样 Gamma 分布、$p_{\mathrm{LLM}} = (1+\delta)p_{\mathrm{human}}$（δ ~ U(0.5, 5)），验证了估计器对真实 β 的高精度还原。

## 实验与结果
- **数据集**：PubMed Central (PMC) Open Access Subset，筛选后 1,194,287 篇 2017–2025 年英文论文，需包含 Introduction、Methods、Results、Discussion 四个章节且每部分 ≥250 词。
- **主要结果（全文估计）**：
  - 2023 年：19%；2024 年：52%；2025 年全年：77%；2025 年 12 月：**89%**。
- **分章节结果（随机 255 词裁剪，2025 年 12 月）**：
  - Discussion：**68%**（最高）；Abstract：67%；Results：46%；Introduction：59%；Methods：**32%**（最低）。
- **全文估计（完整章节，2025 年 12 月）**：Abstract 68%、Introduction 63%、Methods 54%、Results 58%、Discussion 78%。
- **国家/地区差异（2025 年全文）**：韩国最高（85%），其次中国（82%）、台湾（80%）；英国最低（28%）；母语英语国家合计 37%，非母语国家合计 72%。
- **语言趋同**：母语英语国家与非母语国家的标记词预-LLM 频率（2022 年）差异显著，但到 2025 年已趋近；预 LLM 频率与 2025 年估计呈负相关。
- **最强结果与提升幅度**：相比 Kobak et al. (2025) 基于频率缺口的 2024 年估计（12%–16%），本文方法对同一时期的估计高出约 2–4 倍（摘要 31%，全文 52%），证明频率缺口系统性低估了真实 LLM 使用比例。

## 相关工作脉络
- **Kobak et al. (2025)**：本文前期工作，识别了 379 个 LLM 标记词并提出基于频率缺口的下界估计；本文在此基础上提出更紧致的无偏估计框架。
- **Gray (2024, 2025)、Kousha & Thelwall (2025)**：同样基于词频缺口的下界估计方法，本文证明这类方法系统性低估实际使用率（如 2024 年估计仅 12%–16%，而本文为 52%）。
- **Liang et al. (2024a, 2025)、Geng & Trotta (2024)**：基于混合模型的方法，通过 prompt 生成 LLM 文本来估计 $p_{\mathrm{LLM}}$；本文指出这类方法结果强烈依赖所选 prompt 和模型（同一数据可得 18% 或 35%），而本文方法无需此类假设。
- **Siler (2026)**：基于标记词使用率分布重叠的方法，得出 2025 年 57% 的估计；本文认为该方法隐含假设人类与 LLM 写作分布不重叠，因而也会低估。
- **LLM 检测器方法**（Akram, 2024; Liu & Bu, 2024; Picazo-Sanchez & Ortiz-Martin, 2024）：检测器已被多次证明不够准确，且多为早期低使用率时段的数据。
- **调查类研究**（Wiley, 2025/2026; Kwon, 2025; Mohammadi et al., 2026）：多项调查显示 LLM 使用率超过 70%，与本文 89% 估计 broadly consistent，但调查存在自我报告偏差。

## 局限性与未来方向
- **线性外推的可信度随时间衰减**：随着距 ChatGPT 发布时间越来越远，用 2018–2022 年数据外推 2025 年 $\hat{p}_{\mathrm{human}}$ 的可靠性降低。
- **人类写作的风格趋同风险**：作者可能无意识地模仿 LLM 写作风格，导致 $\hat{p}_{\mathrm{human}}$ 被高估（从而低估 β）；也有相反效应——作者刻意避免 LLM 标记词。
- **跨国分析使用固定标记词集**：为保证可比性，国家级别分析未针对各国优化阈值 T，部分估计可能偏低。
- **仅限生物医学期刊**：结论推广到其他学科需谨慎。
- **无法区分辅助写作与纯编辑**：方法检测到的是 LLM 痕迹，但不区分直接生成 vs. 语言润色 vs. 翻译辅助。
- **未来方向**：扩展到更多学科、开发动态更新的人类基线模型、结合章节级细粒度分析追踪 LLM 使用的具体环节。

## 研究启发与可借鉴点
- **无偏估计框架可迁移**：基于标记词频率变化 + 线性外推反事实基线 + 阈值优化的方法设计，可迁移到其他领域（如计算机科学、社会科学）的 LLM 使用监测研究。
- **阈值搜索策略**：在离散阈值网格上搜索最大化下界且满足误差约束的最优阈值，这一策略可作为通用的参数选择范式。
- **随机裁剪控制长度偏差**：用固定长度随机片段比较不同章节的 LLM 使用率，有效消除了章节长度差异带来的混杂，该设计可直接复用于其他文本分析任务。
- **模拟验证方案**：用已知真实值的模拟数据验证估计器精度（|β̂ − β| < 0.02），这一验证思路可作为方法论论文的标准实践。
- **跨国/language 对比框架**：将标记词频率与国家母语背景结合分析，揭示 LLM 驱动的语言趋同现象，为跨语言计算语言学提供新的研究视角。

## 关键术语表
- **LLM-assisted writing**：指作者使用大型语言模型辅助完成学术文本的撰写或编辑，包括翻译、润色、段落生成等场景。
- **LLM marker words（LLM 标记词）**：在 LLM 生成文本中出现频率显著高于人类写作、可用于检测 LLM 参与的非内容词汇（如 "these"、"potential"、"delves"）。
- **$\hat{p}_{\mathrm{human}}$（反事实人类基线频率）**：基于 LLM 普及前的历史词频数据，通过线性回归外推得到的"若无 LLM 影响时的预期使用频率"。
- **频率缺口（Frequency gap, Δ）**：观测频率与反事实基线频率之差（Δ = q − $\hat{p}_{\mathrm{human}}$），是 LLM 使用比例的一个保守下界。
- **$\hat{\beta}_{\mathrm{LB}}$（紧致下界估计）**：在混合模型假设下，通过取 $p_{\mathrm{LLM}} \leq 1$ 的上界推导出的更紧致的 LLM 使用比例下界，公式为 $(q - \hat{p}_{\mathrm{human}}) / (1 - \hat{p}_{\mathrm{human}})$。
- **混合模型（Mixture model）方法**：通过测量 LLM 生成文本的词频 $p_{\mathrm{LLM}}$，结合观测频率 q 反推 LLM 使用比例 β 的方法，结果依赖 prompt 和模型选择。
- **Delta 方法**：用于近似复合函数方差的一种统计方法，本文用于传播 q 和 $\hat{p}_{\mathrm{human}}$ 的误差以计算 $\hat{\beta}$ 的标准误差。
- **语言趋同（Linguistic convergence）**：非母语作者因使用 LLM 而使其写作词汇分布向母语作者靠拢的现象，本文观察到 2022–2025 年间显著趋同。

## 可复现要素
- **数据集**：PubMed Central (PMC) Open Access Subset， openly available（https://pmc.ncbi.nlm.nih.gov/tools/openftlist/）；本文使用 2026 年 1 月 23 日发布的半年度基线版本。
- **代码**：已开源，位于 https://github.com/kobaklab/llm-usage-in-pmc。
- **标记词列表**：379 个 LLM 关联标记词（来自 Kobak et al., 2025）。
- **关键超参**：阈值网格 19 个值（log-scale 上 12 个均匀分布 + 0.03–0.7 区间内额外值）；标准误差上限 0.025；$\hat{p}_{\mathrm{human}}$ 上限 0.999；裁剪长度 255 词；回归时期 2018–2022（5 年/60 月度数据点）。
- **模拟超参**：n = 100,000 文档/年；m = 500 标记词；$p_{\mathrm{human}}$ ~ Gamma(shape=2, scale=0.02)；δ ~ U(0.5, 5)。
