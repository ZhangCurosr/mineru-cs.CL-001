# 论文速读：Leveraging Human Reading Behavior for Keyphrase Extraction: A Webcam-based Eye-tracking Corpus

## 一句话总结
本文开发了一套基于普通网络摄像头的低成本眼动数据采集平台，构建了中文图书情报学（LIS）学术摘要眼动语料库（CLIS-ET），并将字符级眼动特征（首次注视时长 FFD、注视次数 FN、总注视时长 TFD）融入多种关键词短语提取（KPE）模型，验证了人类阅读行为信号对提升学术文献关键词短语提取性能的有效性。

## 研究问题与动机
- **现有 KPE 方法忽视人类认知信号**：现有研究主要依赖文本内部线索（词频、位置、句法模式、上下文语义）识别关键词短语，忽略了关键词短语与读者实际注意力分配和认知加工过程之间的关联。
- **中文学术领域眼动语料匮乏**：已有开源眼动语料（如 ZuCo、GECO）多基于英语新闻、小说等通用文本，缺乏面向中文学术文献的资源，难以支撑学科特定的关键词短语提取研究。
- **传统眼动设备成本高昂**：实验室级眼动仪（如 EyeLink 1000 Plus）价格昂贵（$25,000–$40,000+）、部署条件严格，限制了大规模、多参与者数据采集的可行性。
- **低成本的轻量级方案有待验证**：基于网络摄像头的开放式眼动方案在精度上虽不及专业设备，但在通用阅读行为信号采集中具有可扩展性，其在 KPE 任务中的有效性尚需系统评估。

## 核心贡献（创新点）
- **开发了基于 Webcam 的轻量级眼动数据采集平台**：集成开源 SearchGazer 库与 Flask 框架，支持多参与者同步数据采集，大幅降低硬件成本（$0–$200）与部署门槛，与依赖昂贵实验室设备的传统方案形成本质区别。
- **构建了首个面向中文 LIS 学术摘要的眼动语料库（CLIS-ET）**：涵盖 FFD、FN、TFD 三个字符级眼动特征，填补了中文学术阅读眼动资源的空白，区别于 ZuCo 等基于英语通用文本的现有语料。
- **系统评估了眼动特征对多种 KPE 架构的增益效果**：在 BiLSTM、BERT 系列及 T5 系列模型上验证了个体与组合眼动特征的贡献，揭示了不同特征与模型结构的适配规律，优于此前仅在小规模数据集上验证单一特征的有限研究。
- **提供了眼动特征统计显著性分析的实证证据**：通过配对 t 检验量化了各眼动特征在不同模型上的统计显著性，表明 FN+TFD 组合在 Att-BiLSTM+CRF 模型上效果最佳，为认知驱动 KPE 提供了更可靠的证据支持。

## 方法详解
- **眼动数据采集平台**：基于 Flask Web 框架与开源 JavaScript 库 SearchGazer，利用普通笔记本摄像头实现实时注视坐标采集，最高采样频率 60Hz（间隔约 16.67ms），支持多参与者同步实验。
- **字符级眼动特征提取**：以字符为单位记录眼动指标，有效注视阈值设定为 16.7ms–1500ms（对应单次注视 2–91 个连续采样点）；跨参与者取均值，若某字符有效数据不足半数则标记为无效。
- **三大核心眼动特征定义**：
  - **FFD（First Fixation Duration）**：首次注视目标字符的持续时间，反映初始阅读认知加工深度。
  - **FN（Fixation Number）**：注视目标字符的总次数，反映回归频率与再加工程度。
  - **TFD（Total Fixation Duration）**：注视目标字符的累计时长，反映整体认知投入量。
- **KPE 模型设计**：
  - **RNN 系模型**：BiLSTM（基线）、BiLSTM+CRF、Att-BiLSTM、Att-BiLSTM+CRF；眼动特征作为外部特征向量引入，或在注意力机制中作为注意力指示器引导序列标注。
  - **预训练语言模型系**：BERT-base-chinese、RoBERTa-wwm-ext、MacBERT（全词掩码 WWM + N-gram 掩码）、Randeng-T5-784M（中文 T5 架构）。
- **语料构建**：
  - **Abstract-320**：320 篇摘要（1,215 句，64,969 字符），用于眼动实验与五折交叉验证。
  - **Abstract-5190**：5,190 篇摘要（15,999 句，804,210 字符），按 4:1 划分训练/测试集。
- **评估指标**：以 F₁ 分数为基准，分别报告 Top-3、Top-5、Top-10 关键词短语提取结果（F₁@3、F₁@5、F₁@10）；真正例仅计摘要中出现的关键词短语。

## 实验与结果
- **单特征实验（Abstract-5190）**：
  - 在 RoBERTa 模型上，**FN** 特征取得最优 F₁@5 = **44.51%**（较基线 42.76% 提升 +1.75%）。
  - 在 BERT 系列模型中，**FFD** 特征整体表现最稳定，MacBERT+FFD 达 F₁@5 = 42.85%，RoBERTa+FFD 达 F₁@5 = 44.36%。
  - BiLSTM 系模型中，**FFD** 和 **FN** 均显著优于基线（BiLSTM+FFD：F₁@5 = 25.05%，较基线 22.78% 提升 +2.27%）。
- **组合特征实验（Abstract-5190）**：
  - **FN+TFD** 组合在 **Att-BiLSTM+CRF** 模型上取得最佳性能：F₁@5 = **36.79%**（较基线 33.80% 提升 **+2.99%**），F₁@10 = 35.46%（较基线 31.40% 提升 +4.06%）。
  - **FFD+FN+TFD** 三特征组合在 BiLSTM 模型上表现最优：F₁@5 = 25.73%（较基线 22.78% 提升 +2.95%）。
- **统计显著性（Abstract-320，五折交叉验证）**：
  - 配对 t 检验（p < 0.05）显示，眼动特征在多个模型上均达统计显著水平；**FFD+TFD** 和 **FN+TFD** 组合在多数模型上 p 值最低（如 BiLSTM+FFD+TFD: p=0.0036**；ATT_BiLSTM+FN+TFD: p=0.0023**）。
  - Randeng-T5 模型中，**FN+TFD** 组合达到最高显著性（p=0.0006**）。
- **关键结论**：眼动特征对不同模型架构的增益存在异质性；小规模数据集上早期加工特征（FFD）信息增益更大，大规模数据集上累积加工特征（TFD）支持更深语义建模；互补特征对（如 FN+TFD）优于简单叠加所有特征。

## 相关工作脉络
- **ZuCo 语料（Hollenstein et al., 2018）**：基于英语 Wikipedia 文本的双模态（EEG+眼动）语料，本文区别于其英语通用文本设置，聚焦中文 LIS 学术摘要领域。
- **Zhang & Zhang（2021）**：利用 ZuCo 语料的 TFD 特征增强微博关键词短语提取，本文扩展至中文学术语境并引入多特征与多模型系统评估。
- **Yan et al.（2024）**：结合 ZuCo 语料的 EEG+眼动特征用于微博 KPE，本文以纯眼动特征为主且针对学术文献，设备成本大幅降低。
- **YAKE（Campos et al., 2020）**：纯统计无监督关键词提取方法，本文与之本质区别在于引入人类认知行为信号而非仅依赖文本内部统计特征。
- **GECO/GECO-CN 语料（Cop et al., 2017; Sui et al., 2023）**：基于小说文本的双语眼动语料，本文填补了学术摘要领域中文眼动资源的空白。
- **MacBERT / RoBERTa / Randeng-T5**：中文预训练语言模型基线，本文验证眼动特征在强预训练架构下的补充价值，区别于此前仅作用于 RNN 系模型的研究。

## 局限性与未来方向
- **设备精度限制**：Webcam 方案（60Hz）远低于实验室级设备（500–2000Hz），在精细眼动指标（如瞳孔直径、微扫视）采集中存在局限，不宜直接替代高精度眼动实验。
- **样本规模有限**：仅 10 名参与者，虽与已有语料规模相当，但可能不足以充分捕捉个体差异与阅读风格多样性。
- **领域覆盖单一**：语料仅限于 LIS 领域三本中文核心期刊，结论推广至其他学科需谨慎。
- **特征组合异质性**：不同模型对眼动特征的响应模式不一致（如 RoBERTa 对 FN 更敏感，BERT 对 FFD 更敏感），尚未形成统一的特征融合策略。
- **未来方向**：扩展至更多学科与参与者；探索更细粒度的特征融合机制（如动态权重分配）；将眼动信号引入注意力机制的内生设计而非仅作为外部特征；支持远程大规模数据采集以构建更具代表性的中文学术眼动资源。

## 研究启发与可借鉴点
- **低成本眼动采集方案的可行性验证**：Webcam+SearchGazer 方案可作为快速构建领域眼动语料的通用模板，适用于其他需要行为信号辅助的 NLP 任务（如情感分析、关系抽取）。
- **字符级眼动特征的外部注入范式**：将 FFD/FN/TFD 以字符向量形式拼接至模型输入层，或作为注意力权重的引导信号，这一设计可迁移至命名实体识别、文本摘要等序列标注任务。
- **特征-模型适配规律**：小规模数据偏好早期加工特征（FFD），大规模数据偏好累积加工特征（TFD），这一发现为不同规模数据集上的特征选择提供了实用指导原则。
- **多特征互补的组合策略**：FN+TFD 等双特征组合在某些模型上优于三特征全量叠加，提示后续研究应关注特征间的交互效应而非简单堆叠，可探索门控机制或注意力加权融合。
- **认知信号与预训练模型的协同**：眼动特征在 RoBERTa/MacBERT 上仍能提供显著增益，表明预训练模型的上下文表征与人眼注意力模式存在可互补的信息维度，为多模态预训练提供了新思路。

## 关键术语表
- **Keyphrase Extraction（KPE，关键词短语提取）**：从文本中自动识别出最具代表性、能概括主题的核心词组，是信息检索与文献分析的底层任务。
- **First Fixation Duration（FFD，首次注视时长）**：读者第一次注视某字符时的停留时间，反映初始词汇加工难度与认知负荷。
- **Fixation Number（FN，注视次数）**：注视目标字符的累计次数，数值越高通常意味着该字符需要更多再加工或信息量更大。
- **Total Fixation Duration（TFD，总注视时长）**：所有注视目标字符的时长之和，综合反映对该字符的整体认知投入。
- **SearchGazer**：开源 JavaScript 眼动追踪库，通过浏览器调用摄像头实现 Web 端实时注视坐标推断，支持 60Hz 采样。
- **CLIS-ET（Chinese LIS Eye-Tracking Corpus）**：本文构建的中文图书情报学学术摘要眼动语料库，包含 320 篇摘要的字符级眼动特征标注。
- **Abstract-5190**：基于三本中文 LIS 核心期刊构建的大规模关键词短语提取数据集，共 5,190 篇摘要，用于验证眼动特征的泛化效果。
- **Att-BiLSTM+CRF**：引入注意力机制的 BiLSTM 结合条件随机场（CRF）的序列标注模型，本文中眼动特征对其性能提升最为显著。
