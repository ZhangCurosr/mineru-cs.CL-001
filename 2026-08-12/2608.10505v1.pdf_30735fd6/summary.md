# 论文速读：RadFusion: Towards Threshold-Controllable Radiology Report Generation

## 一句话总结
RadFusion 首次提出了一种阈值可控制的放射学报告生成框架，通过将分类器的置信度分数与 VQA 报告生成器融合，并利用 LLM 重写报告使其诊断结论与阈值化分类决策保持一致，从而实现了报告生成中灵敏度-特异性的可调节权衡，并支持 ROC 曲线评估。

## 研究问题与动机
- **现有报告生成模型缺乏诊断可调控性**：当前基于图像描述的方法只能生成单一固定报告，无法根据临床场景（如急诊筛查 vs. 确认性评估）调整诊断敏感度与特异度的权衡。
- **感知模型虽可阈值控制但表达能力有限**：分类器可通过置信度阈值实现 ROC 分析，但无法描述病灶的解剖位置、严重程度、进展等丰富临床细节。
- **缺乏支持监管审批的量化评估路径**：FDA 等监管机构期望基于 ROC 的分析验证，但现有生成模型没有置信度估计机制，难以进行此类定量评估。
- **可控文本生成方法不适用于临床诊断场景**：现有可控生成研究关注 token 级属性控制或答案置信度自评估，未涉及基于类别特定阈值的诊断操作点选择。

## 核心贡献（创新点）
- **首次实现报告生成的阈值可控性**：提出 RadFusion 框架，使报告诊断内容与分类器的 ROC 特性对齐，突破传统报告生成模型固定输出模式。
- **三重组件融合架构**：将校准的多标签分类器、支持后续查询的 VQA 报告生成器（QRad）、以及免训练的 LLM 重写器有机结合，实现数值置信度与文本描述力的互补。
- **报告 ROC 与分类器 ROC 严格对齐**：证明通过调节阈值，生成报告的 ROC 曲线紧密追踪底层分类器的 ROC 曲线，使报告可进行定量 ROC 分析评估。
- **诊断准确性显著提升**：相比无控制生成，在匹配特异度下敏感度提升 6.9%，在匹配敏感度下特异度提升 20.7%。
- **可扩展至三维阈值控制**：提出将阈值空间扩展到三维（两个置信度边界 + 一个紧急度阈值），支持分级决策和临床语境自适应。

## 方法详解
**整体架构（图 1）**：
- **感知模型（分类器）**：对每张胸部 X 光片输出 K 个预定义疾病类别的校准置信度分数 $\{ \bar{P}(C_i=1) \}_{i=1}^{K}$，给定阈值 τ 产生二值预测 $\hat{y}_i = \mathbf{1}[P(C_i=1) > \tau]$。
- **报告生成模型（QRad Auto-VQA）**：将报告生成重构为自导向视觉问答过程 $Q = f_Q(I), Y = f_A(I, Q)$，可针对初始报告中遗漏的发现进行后续查询获取证据。
- **LLM 重写器**：将分类器的二值决策与证据池（初始报告 + 可选后续答案）结合，重写报告使其诊断与阈值化分类一致，同时保留原始报告中的临床细节。

**分类器三种实现方式**：
1. **MI2 微调分类器（默认）**：基于 MedImageInsight 模型，使用 Image-Text-Class Hybrid Contrastive Loss 微调，公式：$\mathcal{L} = \mathcal{L}_{image-text} + \lambda \mathcal{L}_{image-class}$，并通过温度缩放校准。
2. **QRad 编码器线性探测**：在 QRad 冻结的图像编码器上训练线性分类头，与报告生成共享编码器，降低计算开销。
3. **QRad 单 token 概率**：提取 QRad VQA 回答中 [Yes]/[No] 的 softmax 概率作为类别置信度。

**LLM 重写指令设计**：
- 对每个正类：若报告中已提及则保留，若缺失或矛盾则用证据池中的细节添加/修正。
- 对每个负类：若报告中提及则移除或否定。
- 非类别内容（如成像质量、未在类别集中的支撑设备）保持原样。
- 提供每类的示例文本段作为模板字典，帮助建立类别名称与自然语言表述的对应关系。

**三维阈值扩展**：
- $T_a, T_b$ 划分置信度为阴性区、阳性区和半阳性区（明确标注不确定性并建议进一步评估）。
- $T_c$ 阈值化紧急度评分，对时间敏感的发现进行强调。

## 实验与结果
**数据集**：MIMIC-CXR，包含 227,835 项研究、377,110 张胸部 X 光片，使用官方测试集（2,347 项研究），以 Findings 部分作为生成目标。

**评估方法**：闭环评估协议——从分类器阈值化决策出发，经 LLM 重写报告后，用 GPT-5 将报告转换回二值类别标签，计算 TPR（敏感度）和 FPR（1-特异度）， Sweep τ 从 0.0 到 1.0（步长 0.1），绘制报告 ROC 曲线并与分类器 ROC 对比。

**主要结果**：
- **AUC-ROC 对比**（表 1）：MI2 FT 平均 AUC 为 0.90，QRad Linear Prob 为 0.91，QRad Token Logit 为 0.73。
- **报告 ROC 与分类器 ROC 紧密对齐**（图 2、图 4）：跨 13 个疾病类别，阈值控制报告的 ROC 曲线（红色）紧密追踪分类器 ROC（蓝色）。
- **诊断准确性提升**：在匹配特异度下敏感度提升 6.9%，在匹配敏感度下特异度提升 20.7%（图 4 绿色十字为无控制报告的单点）。
- **LLM 重写器对比**（表 2、表 3）：GPT-5 默认达到平均 AUC 0.90；移除每类示例文本导致 Fracture 从 0.89 降至 0.73，平均降至 0.88；GPT-5.4-mini 在默认推理强度下表现较差（平均 0.76），但提升至 medium 推理后恢复至 0.89。
- **分类器实现对比**（图 5）：QRad Linear Prob 在难检测类别（如 Pneumothorax）上更强，MI2 FT 在明显视觉类别（如 Support Devices）上更强。

## 相关工作脉络
- **早期报告生成模型**（R2Gen、R2GenCMN）：采用编码器-解码器架构，仅生成单一固定报告，无诊断可控性。
- **大型视觉-语言模型报告生成**（LLaVA-Rad、MAIRA、CheXagent、MedVersa 等）：性能持续提升但仍缺乏置信度估计和阈值控制机制。
- **可控文本生成**（PPLM、FUDGE、Classifier-free Guidance）：在 token 级别引导生成，不支持类别特异性诊断阈值。
- **医疗视觉问答**（Med-Flamingo、LLaVA-Med、Rad-ReStruct）：提供查询接口但本身不生成完整报告，本文利用其补充报告遗漏信息。
- **置信度估计与校准**（温度缩放、P(True) 提取、自我一致性）：为分类器校准提供基础，但未被整合到报告生成流程中。
- **QRad**（Jin et al.）：本文采用的报告生成组件，将报告生成重构为 Auto-VQA，支持后续查询获取遗漏证据。

## 局限性与未来方向
- **组件误差传播**：分类器错误会传递至重写报告，报告生成器可能遗漏发现，LLM 重写器可能引入细微的语言 artifacts。
- **模板依赖**：重写指令为模板化设计且针对胸部 X 光 findings 优化，对不同重写器、成像模态或临床领域需重新调优。
- **预定义类别限制**：阈值控制仅作用于预定义疾病类别集合，类别外发现不受阈值调节。
- **自动标签提取误差**：评估依赖从报告中自动提取标签，可能引入额外误差。
- **未来方向**：探索医生可调的操作点界面、扩展至更多医学成像模态和临床领域、将三维阈值控制应用于实际临床工作流。

## 研究启发与可借鉴点
- **感知-生成混合架构**：将分类器的数值置信度与生成器的丰富表达能力融合的思路，可迁移至其他需要可控输出的医疗文本生成任务（如病理报告、超声报告）。
- **Auto-VQA 补充遗漏信息**：通过后续查询获取初始生成中遗漏的证据，这一机制可有效缓解报告生成中的遗漏问题，值得在其他生成任务中借鉴。
- **闭环 ROC 评估协议**：将生成文本映射回标签并绘制 ROC 曲线的评估方法，为生成模型的诊断性能提供了可与监管要求对齐的定量评估路径。
- **LLM 免训练重写策略**：利用现成 LLM 配合精心设计的指令完成专业化重写，避免从头训练专用模型，降低了部署成本。
- **示例模板增强指令遵循**：为每个类别提供正负示例文本段显著提升重写质量，这一提示工程技巧在其他需要精确约束输出内容的任务中具有普适价值。

## 关键术语表
**阈值可控性（Threshold-controllable）**：通过调节置信度阈值来调整模型诊断敏感度与特异度权衡的能力。
**ROC 曲线（ROC Curve）**：以假阳性率为横轴、真阳性率为纵轴绘制的曲线，反映分类器在不同阈值下的性能权衡。
**Auto-VQA**：自导向视觉问答，模型自主生成临床相关问题是并依次回答以构建报告的过程。
**温度缩放（Temperature Scaling）**：后处理校准方法，通过学习标量 T 最小化 ECE 来提升概率估计的校准度。
**灵敏度-特异度权衡**：敏感度（正确识别阳性病例的能力）与特异度（正确识别阴性病例的能力）之间的此消彼长关系。
**Operational Point（操作点）**：ROC 曲线上对应特定阈值的具体性能点，代表一种风险偏好配置。
