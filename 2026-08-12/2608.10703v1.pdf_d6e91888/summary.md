# 论文速读：Your LLM, Your Style: Behavioral Mode Axes for LLM Behavioral Control

## 一句话总结
本文提出基于情境行为数据（B-data）的LLM行为控制框架，通过20种行为模式与4类交互语境的对比探针，揭示模型行为风格在不同语境下的稳定性与漂移，并首次构建“行为模式轴（BMA）”，证明利用中间推理层激活方向可对LLM行为模式实现干净、跨语境的双向控制，有效规避响应层向量导致的机制污染。

## 研究问题与动机
1. **自陈式问卷测量不稳定**：现有LLM人格研究直接施用Big Five、MBTI等量表进行第一人称自评，得分高度敏感于提示词措辞、选项顺序、推理设置等表面因素。
2. **自评分数与实际行为脱节**：大量证据表明模型在问卷中报告的“特质”与其在具体情境中的选择、建议策略和任务执行行为并不一致。
3. **缺乏跨交互语境的一致性检验**：现有研究几乎全部限定在第一人称描述框架，未检验同一模型在提供建议或执行任务时是否保持相同的行为特征。
4. **现有激活控制存在机制污染**：基于最终回复提取的激活方向往往混杂输出格式、社交偏好等非目标机制，导致干预时出现“到达目标选项但驱动机制被替换”的问题。

## 核心贡献（创新点）
1. **提出B-data情境化行为数据框架**：将LLM“人格”从抽象自评标签转化为可观测的选择、建议与任务行为，覆盖20种行为模式与4类交互语境，弥补传统S-data/I-data的测量偏差。
2. **引入行为模式轴（BMA）实现因果控制**：证明LLM行为倾向可通过激活空间线性方向进行双向调控，且控制效果集中分布在早期至中层的“行为控制层带（BCL bands）”，跨模型族与规模泛化。
3. **区分思维层（BMA-T）与响应层（BMA-R）并揭示特质漂移**：发现仅基于最终回复提取的BMA-R会激活无关机制（如敷衍、低投入），而基于中间行为推理提取的BMA-T能更忠实地捕获目标行为机制，提供干净的跨语境控制。
4. **建立行为轮廓跨语境基准**：量化同一模型不同语境下的剖面相关性（均值0.76，跨度0.37~0.97），并证实问卷自评与实际行为的平均差距达22.7个百分点，最大子维度差距达47.5个百分点。

## 方法详解
1. **情境行为探针构建**：基于BFI-2、DOSPERT、HEXACO、GCS、UPPS等验证性维度，构造3,200组对比情境（20子维度 × 4语境：第一人称选择、日常建议、任务建议、任务执行）。每个情境包含两个同等合理但行为模式相反的二选一选项，要求模型选择并说明理由，以规避社会赞许性偏差。
2. **行为轮廓估计与稳定性检验**：将回复解析为低极/高极模式，按子维度与语境聚合高极率生成20维剖面；分半信度检验显示同一语境内剖面高度稳定（split-half r=0.933，Spearman-Brown校正后）。
3. **BMA提取**：
   - **BMA-R**：从最终回复token激活计算均值差 $\tilde{v}_\ell^R = \frac{1}{N}\sum(\bar{h}_\ell^R(\text{low}) - \bar{h}_\ell^R(\text{high}))$。
   - **BMA-T**：从中间行为推理token激活计算均值差 $\tilde{v}_\ell^T = \frac{1}{N}\sum(\bar{h}_\ell^T(\text{low}) - \bar{h}_\ell^T(\text{high}))$，强制分离“动机”与“动作输出”。
   - 两向量经L2归一化后用于推理干预：$h_\ell^{(t)} \gets h_\ell^{(t)} + c v_\ell^z$（prefill与decode阶段同步应用）。
4. **纯净控制区间与BCL定位**：定义“纯净方向范围”，要求未知/无法解析生成率<1%且重复率<5%，寻找跨20子维度均能稳定调控的连续层带，即Behavioral Control Layer（BCL）。

## 实验与结果
- **评测设置**：7个开源模型（Llama-3.1-8B/70B, Qwen2.5-7B/14B/32B, Gemma-2-2B/9B/27B-it），评估探针与BMA提取探针严格分离。
- **自陈vs行为差距**：平均差距22.7个百分点，34.4%配对差距≥25分，Negative Urgency子维度差距最大（47.5分）。
