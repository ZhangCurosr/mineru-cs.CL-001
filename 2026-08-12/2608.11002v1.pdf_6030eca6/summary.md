# 论文速读：On the Limitations of Cross-Lingual Consistency in Multilingual Text-to-image Generation

## 一句话总结
本文提出 **LingT2I**，一个覆盖 10 种语言、3.3 万提示词的基准测试，首次系统评估了多语言 T2I 生成在内容创作与文字渲染两方面的跨语言能力，揭示了现有模型存在严重的“语言不平等”、非拉丁文字系统的结构性瓶颈，以及语言特有的多维性能权衡与文化依赖模式。

## 研究问题与动机
*   **核心问题：** 现有的文本到图像（T2I）生成研究主要集中于英语，模型在多语言场景下的真实能力、以及不同语言之间的性能差距（即跨语言一致性）缺乏系统性理解和评估。
*   **现有方法不足：**
    1.  **评估缺失：** 以往的多语言T2I研究多聚焦于提升图像质量，而忽视了对语言特性、文字系统差异以及文本渲染等关键维度的评估。
    2.  **现象零散：** 虽有零星研究探讨非拉丁字符或特定语言的表现，但缺乏一个统一的基准来全面揭示语言不平等、多维度权衡及文化依赖的生成模式。
    3.  **根源不明：** 不同语言间性能差距的根本原因（如数据分布、语言形态学、文字系统复杂度）尚未得到清晰剖析，限制了针对性改进。

## 核心贡献（创新点）
*   **提出 LingT2I 基准：** 构建了首个专为分析跨语言效应设计的统一基准，涵盖内容生成和文字渲染两大任务，覆盖10种语言和3.3万提示词。*区别在于，此前的工作多为单一任务或孤立语言研究，缺乏如此大规模、多任务、多语言维度的系统性基准。*
*   **首次全面的跨语言分析：** 对17个主流T2I模型进行了广泛的跨语言评估，首次量化并揭示了模型中普遍存在的“语言不平等”现象及语言特定的多维度性能权衡。*区别在于，之前缺乏对多种评估维度（如真实性、忠实度、风格、偏见等）在跨语言语境下如何相互影响的深入分析。*
*   **发现并分析语言依赖的生成模式：** 不仅提供定量结果，还深入发现了模型输出受语言背后文化语境系统性影响的多种模式（如人口统计偏差、文化倾向、文字渲染错误模式）。*区别在于，以往工作多关注整体性能分数，较少深入挖掘和解释语言本身如何塑造生成内容的细节特征。*
*   **提供因果分析洞察：** 通过词元化分析、音译控制实验等，指出了低资源语言性能差的潜在原因（如分词效率低）并非仅由文字表面形式决定。*区别在于，超越了相关性描述，尝试探究导致跨语言性能差距的内在机制。*

## 方法详解
*   **LingT2I 基准构建：**
    *   **任务定义：** 分为 **Content Generation**（内容生成）和 **Text Rendering**（文字渲染）两个子任务。
    *   **语言覆盖：** 选取10种语言（EN, ZH, HI, ES, AR, FR, PT, RU, JA, KO），兼顾使用者数量、全球覆盖率、语言权力指数（PLI）及文字系统多样性（拉丁、汉字、天城文、阿拉伯文、西里尔文等）。
    *   **内容生成子集：** 基于 DOCCI 数据集，利用 Gemini 2.5 Flash/Pro 进行维度感知的提示词构建与多语言翻译，涵盖10个评估维度（图像质量、任务对齐、多样性、鲁棒性），共30K提示词。
    *   **文字渲染子集：** 基于 EasyText，固定英文背景描述，仅翻译需渲染的文字部分，以隔离语言变量，共3K提示词。
    *   **质量控制：** 采用自动处理与验证（回译、GPT-5交叉检查）、错误分析与迭代优化、人工质量检查三层流程，确保98%样本的跨语言语义一致性。
*   **评估体系：**
    *   **内容生成评估：** 使用改进的 **CLIPScore**（替换为多语言 Meta-CLIP2 编码器）衡量整体图文对齐；使用适配的 **TRIGScore**（基于 Qwen-2.5-VL 72B）进行10个维度的细粒度评估。
    *   **文字渲染评估：** 主要指标为 **Precision**，结合字符级/词级 NED 和句级准确率；辅以 MLLM-as-judge 评估文本质量和背景融合度。
*   **分析框架：** 除了量化评测，还进行语言-维度相关性分析、多维权衡分析、人口统计偏差分析、文化倾向分析以及文字渲染错误模式分析（按字符类别、笔画数、序列位置）。

## 实验与结果
*   **数据集与基线：** LingT2I 基准；评估了17个模型，包括通用模型（SD3.5, SDXL, FLUX, Sana, Qwen-Image 等）、多语言增强模型（PEA, X2I, MuLan, Lumina-Next, Z-Image 等）和文字渲染专用模型（Nano Banana, AnyText, EasyText 等）。
*   **主要结果：**
    *   **语言不平等显著：** 通用模型（如 SD3.5, SDXL, FLUX）在不同语言间性能方差大，高资源印欧语系（英、西、法）表现远优于低资源语言（印地语、阿拉伯语）。多语言增强模型（如 PEA, X2I, MuLan）方差降低，但常在特权语言上牺牲性能。
    *   **原生多语言架构更优：** **Qwen-Image** 在保持高整体质量（平均 CLIPScore 0.78）的同时实现了极低的跨语言方差（0.03），优于后适配方法。
    *   **文字渲染是瓶颈：** 所有模型在文字渲染任务上表现普遍较弱，且语言不平等依旧严重。即使专为渲染设计的 **EasyText**，其平均精度也仅为0.67，且非拉丁文字（如阿拉伯语、印地语）精度大幅下降。
    *   **多维度权衡因语言而异：** 不同语言在真实性、忠实度、风格、偏见等维度间呈现不同的权衡关系。例如，高资源语言在风格一致性上可能更好，但可能存在更高的社会偏见；非印欧语言可能因语义接地较弱而表现出较低的偏见分数。
    *   **最强结果：** 在内容生成任务中，**Qwen-Image** 综合表现最佳（平均0.78，Std 0.03）；在文字渲染任务中，**EasyText** 表现最佳（平均精度0.67，Std 0.14）。

## 相关工作脉络
*   **多语言 T2I 生成模型：** SD 3.5 [54], FLUX [29], Z-Image [62] 等通用模型主要依赖预训练多语言文本编码器；HunyuanImage-3.0 [61], Janus-Pro [9] 等自回归模型将多语言能力内嵌于 LLM 主干；Qwen-Image [70] 等通过统一语言与视觉建模空间实现多语言。
*   **多语言增强方法：** AltDiffusion [75] 使用 AltCLIP；GlueGen [43], MuLan [72] 关注编码器-生成器对齐；PEA-Diffusion [36], X2I [37] 利用参数高效微调或知识蒸馏。*本文将它们纳入统一基准进行比较，并指出原生架构（如 Qwen-Image）可能比后适配方法更有效。*
*   **多语言文字渲染模型：** Glyph-ByT5 [33, 34], AnyText [65, 66], EasyText [35] 等通过字形感知编码器、OCR引导特征等方式提升渲染能力。*本文评估了这些专用模型，并发现其在非拉丁文字上仍面临巨大挑战。*
*   **T2I 偏见与跨语言效应：** NLP领域已有大量关于语言不平等的研究 [4, 25, 49]。T2I领域的偏见研究多集中于社会 [3, 28]、文化 [27, 76]、地理 [2, 20] 偏见，且大多基于英语提示。*本文通过多语言系统评估，将语言作为核心变量，揭示了与语言/文字系统直接相关的新型偏见和生成模式，并将内容生成偏见与文字渲染精度联系起来分析。*
*   **现有基准与评估：** 如 HEIM [31], TRIGScore [77] 等提供了多维图像生成评估，但非多语言。NeoBabel [15] 研究了原生多语言生成和跨语言一致性。*本文的 LingT2I 是首个专门针对跨语言效应、覆盖内容生成与文字渲染、进行大规模系统性分析的基准。*

## 局限性与未来方向
*   **局限性：**
    1.  基准构建依赖翻译，虽经严格质量控制，但仍可能引入细微偏差。
    2.  现有评估指标（如CLIPScore）并非完全语言无关，尽管本文已采取措施（使用多语言编码器、调整评估协议）提高公平性。
    3.  观察到的性能差距很大且一致，可能无法完全由上述因素解释，但其具体影响程度难以精确量化。
*   **未来方向（基于论文见解）：**
    1.  **架构设计：** 多语言能力应通过原生架构设计实现，而非后适配。
    2.  **数据构建：** 训练数据应按语系组织，并进行文化 grounding。
    3.  **平衡优化：** 模型应在多个评估维度上保持平衡性能，避免过度优化单一质量方面。
    4.  **偏见缓解：** 结合偏见感知的数据收集和基于翻译的数据增强，以减轻文化和人口统计偏见，提高跨语言公平性。
    5.  **文字系统：** 针对复杂书写系统，开发专用的渲染模块或训练策略。

## 研究启发与可借鉴点
*   **维度感知的提示词构造与评估框架：** 采用 LLM 从原始描述中提取与特定评估维度相关的语义信息，并据此构造或调整提示词（如添加风格控制词），可用于构建更精细、可解释的多维度图像生成评估体系。
*   **结合语言类型学与文字系统的分析视角：** 将语言分支、文字系统类型（字母、语素、音节）、字符复杂度（笔画数）、书写方向等因素系统性地纳入 T2I 模型分析，有助于更深入地理解性能差异的根源，这一分析框架可迁移至其他多模态模型的研究。
*   **因果分析揭示性能瓶颈：** 通过词元化碎片率与性能的相关性分析，以及音译控制实验，证明了文本侧表示效率是性能差距的关键因素，而不仅仅是文字视觉外观。这种寻找内在机制的分析方法具有启发性。
*   **关注多维权衡而非单一指标：** 论文展示了不同语言在同一模型上可能在不同评估维度间呈现不同的权衡关系（如毒性-风格、对齐-精度）。未来的模型评估和发展应避免只优化单一总分，而需关注多维度的均衡表现。
*   **开源基准促进社区发展：** 公开 LingT2I 基准和评估代码，为社区提供了一个标准化的平台，便于公平比较不同模型的多语言能力，并推动针对发现问题的专项研究。

## 关键术语表
*   **LingT2I:** 本文提出的基准测试名称，用于系统评估文本到图像生成模型在多语言环境下的跨语言能力。
*   **Cross-lingual Inequality (语言不平等):** 指T2I模型在不同语言提示下生成的图像质量存在显著且系统性的差异，通常高资源语言表现优于低资源语言的现象。
*   **Content Generation (内容生成):** LingT2I基准中的任务，评估模型根据多语言提示词生成符合语义描述的图像的能力。
*   **Text Rendering (文字渲染):** LingT2I基准中的任务，评估模型在多语言图像中准确生成指定文字内容的能力。
*   **CLIPScore:** 一种参考-free的评估指标，通过计算图像和文本提示在CLIP嵌入空间中的余弦相似度来衡量图文对齐度。本文改用多语言版本 Meta-CLIP2。
*   **TRIGScore:** 基于多模态大语言模型的细粒度评估指标，用于从多个预定义维度（如真实性、原创性、内容对齐等）对生成图像进行评分。
*   **NED (Normalized Edit Distance):** 归一化编辑距离，用于评估文字渲染精度，本文同时使用字符级和词级NED。
*   **Power Language Index (PLI):** 语言权力指数，用于衡量语言在全球影响力、经济和技术领域的地位，本文用于辅助选择基准测试语言。

## 可复现要素
*   **数据集:** LingT2I 数据集已在 Hugging Face 开源 (https://huggingface.co/datasets/RISys-Lab/LingT2I)。
*   **代码:** 基准相关的 GitHub 仓库已提供 (https://github.com/RISys-Lab/LingT2I)，但具体模型的评测代码实现细节需参考附录及仓库。
*   **关键超参数:** 实验使用4块 NVIDIA A100 64GB GPU。各模型使用其官方推荐的默认设置（如生成步数、分辨率、引导尺度），种子固定为42。评估使用 metaclip-2-worldwide-huge-quickgelu 和 Qwen-2.5-VL 72B。
