# 论文速读：Every Token Counts: Exact Likert-Scale Distributions for Measuring LLM Attitudes and Biases

## 一句话总结
本文提出了一种精确的概率质量函数（PMF）分析框架，通过完全交叉因子实验设计、直接操作 token 级精确概率分布、以及分布式的方差分析（ANOVA）来隔离大语言模型行为偏差的因果主效应与交互效应，并以消费者民族中心主义为案例，展示了该方法如何在消除蒙特卡洛采样噪声的同时，揭示被传统聚合基准测试掩盖的系统性国家起源偏见。

## 研究问题与动机
1. **聚合基准测试混淆因果机制**：现有 NLP 社区广泛使用大规模非结构化基准数据集评估 LLM 泛化能力，但这类"规模优先"范式无法区分检测到的偏差究竟源于模型的基线特质、情境混淆变量还是复杂交互作用。例如，检测到对女性角色的系统性偏见时，无法判断是性别本身的效应（主效应）、特定情境的效应（如"企业领导力"），还是两者的交互效应。
2. **文本采样引入不可接受的噪声**：NLP 领域借鉴人类行为科学的抽样范式，通过 Monte Carlo 文本生成来模拟"人群"响应，但这实质上是从 LLM 静态概率分布中反复抽取带有噪声的样本；标准采样预算下（N=100），对小效应（|E|<1）的翻转概率仍高达 6.3%，且温度等非默认解码策略会引入无法通过增加采样消除的系统性偏差。
3. **熵等标准不确定性度量不适用于有序量表**：Shannon 熵在处理无序分类变量时有效（如幻觉检测），但完全忽略 Likert 量表的有序性质——无法区分在"强烈同意"（5）与"强烈反对"（1）之间两极分化的分布和集中在"中立"（3）附近的平滑分布。
4. **心理测量学方法向 LLM 迁移存在三大方法学鸿沟**：即实验设计鸿沟（缺乏因果隔离）、测量鸿沟（采样噪声替代精确分布）、分析鸿沟（缺乏处理有序概率分布的统计工具）。

## 核心贡献（创新点）
1. **将 LLM 行为评估形式化为完全交叉固定效应实验**：将模型身份、目标人口/情境变量视为独立因子，通过系统地评估所有可能组合，数学上隔离因果主效应和高阶交互效应，与"规模优先"的非结构化基准测试形成根本区别。
2. **直接操作精确 token 级概率质量函数（PMFs）消除采样噪声**：利用 LLM 对给定 prompt 具有恒定且完全可观察的内部状态这一性质，绕过文本生成采样，实现等价于 N→∞ 的单次前向传播精确推断，标准采样方法在低共识模型上引入的误差可达 0.52 个复合分数点。
3. **提出多变量有序共识度量（Multivariate Consensus）**：桥接 Shannon 熵不适用于有序心理测量量表的缺陷，显式以概率乘以距均值的有序距离来量化模型内部一致性，能正确识别极端两极分化与集中分布的行为差异。
4. **推导分布方差分析（Distributional ANOVA）与分布 Hoeffding 分解**：通过最优传输配对对比将复合构念分布精确分解为基线、主效应和交互效应分布，并在期望层面严格恢复经典固定效应 ANOVA 参数（Theorem 3.1），使研究者能够以完整概率分布的形式报告效应大小、方向一致性和信噪比。

## 方法详解
1. **实验设计层**：构建完全交叉固定效应实验，每个因子（如 MODEL、TARGET COUNTRY）具有离散水平，实验条件空间为所有因子的笛卡尔积。每个实验条件 λ 下，模型评估由 K 个有序 Likert 量表题目组成的心理测量工具（如 CETSCALE 的 K=17 题），对每个题目进行单次前向传播并记录精确 next-token PMF。关键假设是：由于模型状态在各题目间重置，给定 λ 下各题目响应条件独立，联合 PMF 可精确分解为各题 PMF 的乘积。
2. **约束层（Constraint）**：处理分词器特殊性（如 BPE 导致的 " 7" vs "7"），定义有效 token 集合 V_val ⊂ V 并通过满射映射 φ 关联到有序数值；计算模型违规率（1 - Σ_{t∈V_val} P_raw(t|x)），对保留在 V_val 上的分布重新归一化，得到精确的有序题目 PMF：P(Y_{k,λ}=y | λ) = Σ_{t∈φ^{-1}(y)} P(t | x_{k,λ}, t∈V_val)。
3. **共识层（Consensus）**：多变量 Consensus 公式为 Cns(Y_λ) = 1 + Σ_{y∈V^K} P(y) log₂(1 - ‖y - μ‖₂ / d_max)，其中 μ 为题级别均值向量，d_max = √K(y_max - y_min) 为 Likert 空间最大对角距离。与熵不同，该度量惩罚两端极化（如 P(1)=0.5, P(7)=0.5）而奖励质量集中在均值附近。
4. **构念层（Construct）**：
   - **复合得分分布的精确计算**：利用离散卷积将题目级 PMF 传播到复合构念得分：P_{S_λ} = P_{Y_{1,λ}} ⊛ … ⊛ P_{Y_{K,λ}}。
   - **分布 Hoeffding 分解**：将整体构念分布分解为基线（Grand Mean S₀）、主效应分布 E_c(λ_c) 和交互效应分布 E_U(λ_U)，期望层面满足 E[S_λ] = E[S₀] + Σ_c E[E_c(λ_c)] + Σ_U E[E_U(λ_U)]（Theorem 3.1 保证与经典 ANOVA 参数的精确对齐）。
   - **配对最优传输对比**：主效应和交互效应通过单调最优传输（comonotone coupling）配对差分计算，最小化配对差的方差，避免独立抽样差分配对的方差膨胀。
   - **效应摘要指标**：均值偏移（E[E]）、预测分散度（SD(E)）、离散方向概率（dPD = max(P(E>0), P(E<0))）、信噪比（SNR = |E[E]| / SD(E)）。

## 实验与结果
1. **实验设置**：使用经过验证的 CETSCALE（K=17 题，7 点 Likert 量表），采用 5×4 对称完全交叉固定效应设计，因子 MODEL 包含 5 个模型（Llama 3.3 70B、Gemma 3 27B、Qwen3 Next 80B、Aya Expanse 32B、Ministral 14B），因子 TARGET 包含 4 个国家（USA、China、Canada、France），共 5×4×17 = 340 个精确题目级 PMF。
2. **约束结果**：Gemma 3、Llama 3.3、Qwen3 违规率接近完美（M < 0.001）；Ministral 有小幅违规（M = 0.002）；Aya Expanse 违规率最高（M = 0.006, SD = 0.049）。
3. **共识结果**：四个模型 Cns > 0.88；Ministral 严重异常（Cns ≈ 0.65–0.67），其 item-level PMF 频繁将大量概率质量分配到 Likert 量表对立两端。
4. **复合得分与人类基准对比（TARGET=USA 条件）**：Aya Expanse 32B 得分最高（E[S]=89.11），超过最民族中心主义的人类样本（底特律：68.58）；Llama 3.3 70B（71.99）和 Ministral 14B（70.20）也超过人类均值；Qwen3 Next 80B 最低（53.85）。
5. **主效应**：Aya-32B 展现严重正向偏离（E = 21.19, SNR = 1.63, dPD > 0.99）；Qwen3-80B 展现强负向效应（E = −14.63, SNR = 1.20, dPD = 0.93）；TARGET 方面，中国作为目标国时所有模型民族中心主义显著下降（E = −6.46, SNR = 1.04, dPD = 0.95），美国与中国对比 E = 9.30（SNR = 1.34）。
6. **交互效应（国家起源偏见）**：Gemma 3-27B（USA 自身：+3.21）和 Llama 3.3-70B（USA 自身：+2.59）展现正向自身国家交互，符合内群偏好；Aya-32B（加拿大自身：−3.77）和 Qwen3-80B（中国自身：−0.20）未展现正向自身国家交互。
7. **聚合基准 vs 因子分解的对比**：聚合视角认为对法国的偏见是普遍的（E = −1.00），但 Ministral-14B 实际展现正向自身国家偏好（+2.45）；聚合显示对中国普遍惩罚（E = −6.46），但 Aya-32B（+5.35）和 Ministral-14B（+4.54）实际展现强正向交互，揭示了聚合基准的方向性错误。
8. **采样成本量化**：N=100 时低共识模型标准误高达 0.52 个复合分数点；|E|<1 的小效应在 N=10 时 18% 概率翻转，N=100 时仍 6.3%；温度变化对低共识模型（Ministral）引入最高达 2.79 分的系统性偏差。

## 相关工作脉络
1. **心理测量学 LLM 评估**：Jiang 等人（2024）、Li 等人（2024）、Helwe 等人（2025）利用心理测试评估 LLM，但 Shu 等人（2024）证明文本生成方式下的心理测量响应高度不稳定，微小提示扰动即可导致 persona 轴上的响应一致性显著下降。本文通过精确 PMF 操作而非采样来解决此不稳定性。
2. **LLM 不确定性度量**：Farquhar 等人（2024）使用 Shannon 熵及其语义变体检测幻觉；Bentegeac 等人（2025）、Kadavath 等人（2022）表明 LLM 内部 token 概率比直接提示uncertainty 更可靠。本文指出熵对有序量表无效，提出多变量 Consensus 填补这一空白。
3. **LLM 地缘政治与文化偏见**：Shwartz（2022）、Bhatia 和 Shwartz（2023）、Bhatia 等人（2024）、Naous 和 Xu（2025）、Kruspe（2024）记录了 LLM 的系统性地理偏见。本文引入经严格验证的 CETSCALE 心理测量工具替代随意的开放生成评估，并通过因子设计精确隔离国家起源交互效应。
4. **LLM 心理测量评估的生成脆性**：Kabir 等人（2025）发现基于多项选择的心理测量评估在选项重排等微小扰动下输出极端不一致；Jung 等人（2026）系统评估了 LLM 上性取向、种族主义和道德测试的适用性。本文通过精确 PMF 分析从根本上规避了生成脆性问题。
5. **概率预测而非文本生成的趋势**：Kuribayashi 等人（2024）证明使用精确 next-word 概率模拟人类认知行为远优于指令微调提示；本文将此趋势推进到心理测量行为评估领域，实现了从采样范式到精确分布范式的转变。
6. **基准评估的方法论批判**：Santurkar 等人（2023）、Durmus 等人（2024）指出现有 NLP 基准在行为评估上的局限；Wadi 和 Ma（2026）论证了聚合偏差无法区分硬编码训练缺陷与情境依赖适应。本文提出的因子实验框架直接回应了这些批判。

## 局限性与未来方向
1. **实证范围局限**：案例研究仅聚焦于消费者民族中心主义单一构念， deliberate 选择以清晰展示分布式 ANOVA 的内部运作；框架可扩展到其他心理特质、道德价值观和地缘政治偏见，但尚未验证。
2. **语言限制**：所有实验以英语进行，模型在其他语言或文字下是否表现出系统性偏见仍是开放的经验问题。
3. **快照评估**：发现反映测试时模型的潜在状态，可能不适用于未来的权重更新或后续模型版本。
4. **单 token 响应限制**：框架依赖精确 next-token 概率分布，显式设计用于受限的单 token 响应范式（如 Likert 量表）；对完全遮蔽 next-token 概率的提供商不适用。
5. **多 token 推理的扩展挑战**：随着 LLM 越来越多地使用多 token 推理协议（如 Chain-of-Thought），将 Consensus 和 Construct 统计量扩展到集成 latent 多 token 轨迹空间是一个复杂的开放问题。
6. **度量优化风险**：直接针对这些指标优化可能产生"得分好但实际偏见未减少"的模型（ Goodhart 定律风险）。

## 研究启发与可借鉴点
1. **精确 PMF 替代 Monte Carlo 采样的范式转换**：对于需要高可靠性的行为评估任务，直接操作模型内部 token 概率分布可彻底消除采样误差，这一思路可迁移到任何需要稳定估计模型"态度"的场景（如价值观对齐、安全性评估）。
2. **分布方差分析（Distributional ANOVA）的方法论创新**：将经典 ANOVA 从点估计扩展到完整概率分布层面，使用最优传输配对对比分离主效应与交互效应，并可提取 dPD、SNR 等多维摘要指标，适用于需要精确因果归因的任何因子实验场景。
3. **多变量有序共识度量对标准熵度量的补充**：Consensus 度量显式纳入有序距离信息，在 Likert 量表等有序响应场景下比 Shannon 熵更能准确刻画模型的内部一致性，可广泛适用于任何基于有序心理测量工具的任务。
4. **将提示变体作为实验因子的框架扩展性**：框架天然支持将任何混淆变量（如提示措辞、角色设定）提升为一等实验因子，通过相同的分布式 ANOVA 管道量化其主效应和交互效应，避免了当前 NLP 评估中提示敏感性被视为"鲁棒性失败"而非"可测量效应"的困境。
5. **采样噪声的系统性量化方法**：通过精确 PMF 作为 ground truth，可以定量计算标准采样范式在不同 N 预算下的翻转概率和系统性解码偏差，为后续研究设定采样预算的合理下限提供方法论依据。

## 关键术语表
**Probability Mass Function (PMF)**：概率质量函数，描述离散随机变量在各个取值点上的概率分布；本文中指 LLM 对每个 token 的精确 next-token 概率分布。
**Fully Crossed Factorial Experiment**：完全交叉因子实验，所有因子水平的所有可能组合均被测试的受控实验设计，允许数学上隔离主效应和交互效应。
**Multivariate Consensus (Cns)**：多变量有序共识度量，基于 Tastle 和 Wierman（2007）的度量扩展，显式以概率乘以距均值的有序距离来量化有序响应的内部一致性。
**Distributional ANOVA**：分布方差分析，将经典 ANOVA 从点估计扩展到完整概率分布层面，通过 Hoeffding 分解将复合构念分布分解为基线、主效应和交互效应分布。
**Hoeffding Decomposition**：Hoeffding 分解，将多元函数分解为相互独立的各阶分量（常量、主效应、交互效应）的组合，本文在分布层面实现并证明其与经典 ANOVA 参数的期望对齐。
**Comonotone Coupling**：单调耦合（最优传输的一种），通过共享潜变量使两个分布的配对差方差最小化，用于计算主效应和交互效应的配对对比。
**Discrete Probability of Direction (dPD)**：离散方向概率，max(P(E>0), P(E<0))，量化效应分布方向一致性的程度，独立于效应大小。
**Signal-to-Noise Ratio (SNR)**：信噪比，|E[E]| / SD(E)，量化行为偏移的统计可靠性，区分稳健效应与模型内部不确定性的伪影。
**Consumer Ethnocentrism Tendencies Scale (CETSCALE)**：消费者民族中心主义倾向量表，Shimp 和 Sharma（1987）开发的 17 题 Likert 心理测量工具，用于测量实体系统性偏好本国、排斥外国实体的倾向。
**Flip Probability (P_flip)**：翻转概率，有限采样下估计效应方向与真实方向相反的概率，本文用于量化标准 Monte Carlo 采样方法的可靠性损失。
