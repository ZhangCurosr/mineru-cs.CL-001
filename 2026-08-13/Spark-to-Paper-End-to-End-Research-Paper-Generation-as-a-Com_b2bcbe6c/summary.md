# 论文速读：Spark-to-Paper: End-to-End Research Paper Generation as a Composable Skill

## 一句话总结
论文提出 Spark-to-Paper，一种将端到端研究论文生成实现为 **13 个可组合技能**的系统，直接嵌入现有编程助手（如 Claude Code），无需独立代理平台或编排服务；通过实验前承诺、确定性完整性校验与有界自我批判机制，实现高引用有效性（99.5%）和高图表可编辑性（96.4%），同时避免生成虚构结果。

---

## 研究问题与动机
- **现有系统依赖独立基础设施**：当前自主研究代理（如 AI Scientist、AutoResearchClaw、Kosmos/Robin）均为独立应用，需要专用编排服务器、图数据库或集群调度器，与研究者实际使用的编程环境割裂。
- **轻量级写作辅助工具覆盖范围有限**：已有基于编程助手技能的研究工具（如 ARS、Idea2Story）仅覆盖文献检索、大纲生成或片段化写作，未实现端到端真实实验执行与可编辑矢量图生成。
- **长周期生成的可靠性问题**：端到端研究生成涉及数百轮迭代，容易产生引用伪造、数值捏造、前后不一致等问题；现有系统缺乏针对"自证伪循环"（反复得出实验不支持原假设却仍强行推进同一方向）的显式处理机制。
- **研究价值主张**：验证"在已有编程助手中以技能组合方式实现完整研究管线"的可行性，而非构建重量级独立系统。

---

## 核心贡献（创新点）
1. **嵌入式技能架构**：将端到端论文生成拆分为 13 个可组合技能，直接运行于现有编程助手（如 Claude Code）中，复用其文件交互、代码执行、工具调用能力，无需额外部署独立代理平台或服务。
2. **实验前承诺（Preregistration）机制**：在实验执行前锁定评估协议（数据集、基线、指标、消融设计、结果表格结构），实验阶段按承诺执行并生成可追溯证据，防止"结果观察后调整协议"的偏差。
3. **双轨完整性保障体系**：确定性门控（模板/引用/手稿/图表/编译校验）保障可机械验证属性，结合自我批判（Self-Review）与对抗性审查（Adversarial Review）处理语义一致性；同时首次识别并建模"自证伪循环"，通过有界恢复（上限 7 轮）终止无效研究方向。
4. **角色感知的可编辑图表生成**：定量结果图由测量数据直接程序化绘图导出为矢量 PDF；解释性方法图先由图像生成模型生成光栅参考图，再通过 HTML/CSS 迭代重构为可编辑矢量图，兼顾生成质量与出版可用性。
5. **多维度受控评估体系**：在 8 个独立选题上评估引用有效性、伪造检测率、图表可编辑性、审查精确率与生成成本，提供与人类预印本、AI Scientist、Agent Laboratory 等系统的可比对比，并公开完整成本与 token 消耗明细。

## 方法详解

### 3.1 总体执行流程（Stage 0–8）
- **Stage 0 Input Routing**：识别输入类型（简短想法 vs. 完整提案），判定是否存在实测数据，选择 `Proposal Mode`（未观测结果保持未指定）或 `Data-Aware Mode`（定量陈述必须锚定实测数据）。
- **Stage 1 Planning**：生成结构化蓝图（blueprint.json），包含研究问题、贡献、章节结构、符号约定与实验设计方案，并读取目标会议模板要求。
- **Stage 2 Citation**：检索相关文献，通过 DOI/ISBN/arXiv 标识符解析验证元数据，生成 BibTeX 参考文献列表，建立 claim–citation 映射。
- **Stage 3 Writing**：基于蓝图与已验证参考文献生成完整 LaTeX 手稿，跨章节保持术语、符号与实验声明一致。
- **Stage 4 Refinement**：全局修订（去重、术语对齐、论据强化、篇幅调整），重跑确定性校验。
- **Stage 5 Review**：多轮隔离审查（技术正确性、实验设计、证据强度），每条评论须引用具体段落，经三重验证（问题是否存在、是否已解决、是否超范围）后保留有效问题并返回修订。
- **Stage 6 Figure Generation**：分路径生成图表（见第 6 节详解）。
- **Stage 7 Assembly**：整合所有章节、参考文献、图表与模板，编译 LaTeX，执行最终校验。
- **Stage 8 Experiment Execution**（条件触发）：当存在可执行代码与数据时，按承诺的实验设计执行最小必要实验集，记录配置/种子/日志/测量值，将可追溯结果回填至表格、图表与手稿，按证据重新评估并修订声明。

### 4. 实验设计与修订
- 先承诺后执行：规划阶段固定表格结构（列头与行头确定），数值单元格留空等待实测数据填充，形成轻量化预注册。
- 实验可行性评估：若所需代码/数据不可用，记录缺失依赖并将对应结果标记为"未指定"，而非用生成值替代。
- 结果采纳协议（Claim Admission Protocol）：每条声明被标记为 SUPPORTED / PARTIALLY-SUPPORTED / UNSUPPORTED / CONTRADICTED / NEEDS-CONFIRMATION，分别触发保留、收窄、删除、移入局限性或交作者确认等操作；负结果、空结果与 inconclusive 结果均被保留而非删除。

### 5. 完整性与自我批判
- **确定性门控（Deterministic Gates）**：
  - Template Gate / Blueprint Gate：模板结构合规、章节约束、引用样式校验。
  - Citation Gate：未解析/重复/孤立引用检测，DOI/URL 解析验证。
  - Manuscript Gate：占位符残留、无效表格结构、未定义符号、结果完整性（Proposal Mode 拒绝填值，Data-Aware Mode 拒绝无证据支撑的定量陈述）。
  - Figure Gate：定量图必须锚定实测数据，可编辑矢量图必须保留可编辑结构。
  - Compilation Gate：LaTeX 成功编译，交叉引用无报错。
- **自我批判机制**：
  - Self-Review：局部修订后检查术语漂移、冗余、局部不一致。
  - Adversarial Review：多层次独立审查视角（理论、实验、系统），每条评论需引用原文段落并经三重验证。
- **自证伪循环（Self-Refutation Loop）与有界恢复**：当实验反复不支持原假设时，系统可能陷入"持续修订同一方向"的死循环；设计上限 7 轮实验-批判-修订循环，超限后终止当前轨迹，生成失败报告（failure report），重新启动新选题管线。

### 6. 可编辑图表生成
- **解释性图表**（方法图、系统架构图）：图像生成模型 → 光栅参考图 → HTML/CSS 迭代重构 → 渲染为可编辑矢量 PDF；重构过程通过视觉比对逐步修正布局、几何、文本位置。
- **实验结果图表**：直接从测量数据写入 plotting 代码生成 PDF，不涉及图像生成模型，保证定量数据严格锚定实测值。

## 实验与结果

### 评估设置
- **数据集/选题**：8 个独立控制选题（其中 3 个与单遍 baseline 配对比较）。
- **评估维度**：引用有效性、伪造检测率、图表可编辑性、审查精确率、跨模板鲁棒性、生成成本。
- **对比基线**：
  - 人类预印本样本（8 篇，320 条引用）
  - AI Scientist（released papers, 45 篇引用）
  - AI Scientist-v2（workshop set, 64 篇引用）
  - Agent Laboratory（28 篇引用）
  - 单遍 LLM 草稿（同 backbone，3 个配对选题）

### 主要结果
| 系统 | 引用有效性 (%) | 图表可编辑性 (%) | Tokens (M) | 成本 (USD) | 墙钟时间 |
|------|--------------|----------------|-----------|----------|---------|
| 人类预印本 | 97.8 [94.6, 99.4] | 58 [44, 71] | n/a | n/a | n/a |
| AI Scientist | 93 (42/45) | 0 (0/210) | n/r | $10–15 (amort.) | ~12 h/batch |
| AI Scientist-v2 | 91 (58/64) | 3 (0–8) | n/r | ~$20–25/attempt | ≤15 h/run |
| Agent Laboratory | 96 (27/28) | 0 (0/30) | n/r | $2.33 (gpt-4o) | ~19 min |
| 单遍 LLM 草稿 | 81 (76–86) | n/a | 0.11 (0.09–0.13) | $0.66 (0.55–0.76) | 16 min (13–19) |
| **Spark-to-Paper（全栈）** | **99.5 [98.4, 100]** | **96.4 [92.7, 98.6]** | **11.9 [10.2, 13.7]** | **$8.1 [6.9, 9.6]** | **3.2 h [2.6, 3.9]** |

### 消融实验（Table 4）
| 配置 | 伪造检测率 (%) | 审查精确率 (%) | Δ Tokens (M) | Δ USD |
|------|------------|------------|-------------|------|
| 单遍草稿（无门控） | 14 (5/36) | n/a | ref. | ref. |
| 仅门控 | 69 (25/36) | n/a | +8.1 ± 0.9 | +5.3 ± 0.5 |
| 门控 + Self-Review | 81 (29/36) | n/a | +1.1 ± 0.2 | +0.6 ± 0.1 |
| 门控 + Self-Review + Adversarial Review | **92 (33/36)** | **74 (42/57)** | +2.6 ± 0.4 | +1.6 ± 0.2 |

- 伪造检测基准：36 个种子探针，覆盖 10 类失败家族。
- 审查精确率：盲评 57 条审查意见，74% 为可独立验证的真实问题。
- 核心结论：确定性门控贡献最大质量增益，自我批判提供边际改进；全栈系统在保持 $8.1/篇、3.2h 成本的同时实现最高引用有效性（99.5%）与图表可编辑性（96.4%）。

### 案例研究
- **临床风险筛查**：自动识别"Accuracy 在严重类别不平衡场景下具有误导性"的研究空白，引入泄漏安全管线（post-hoc 概率校准 + TreeSHAP 驱动审计）。
- **时间序列预测**：重构传统分解方法为因果滑动窗口特征算子，实证揭示常规全序列分解会因"窥视未来信息"而 inflate 准确率。
- **注入错误先验测试**：在提案中注入"Accuracy 应作为主指标"与"因果模型性能应与分解模型相当"两个错误预期，系统通过实测结果推翻先验，保留负面发现，体现证据优先原则。

## 相关工作脉络
1. **AI Scientist / v2 (Lu et al., 2024; Yamada et al., 2025)**：端到端自主研究代理，能提出并运行新颖实验；定位差异：Spark-to-Paper 无独立编排基础设施，以技能形式嵌入编程助手，且支持可编辑矢量图生成。
2. **AutoResearchClaw (Liu et al., 2026)**：人机协作的自强化研究管线，代码规模达数万行；定位差异：Spark-to-Paper 更轻量，聚焦论文生成而非全周期科学发现。
3. **Kosmos / Robin (Mitchener et al., 2025; Ghareeb et al., 2025)**：开放-ended 科学发现的长周期多代理系统；定位差异：Spark-to-Paper 明确处理"自证伪循环"并在有界恢复后重启，而非无限迭代。
4. **Agent Laboratory (Schmidgall et al., 2025)**：使用 LLM 代理作为研究助理；定位差异：本工作强调实验前承诺与证据驱动声明修订，而 AL 未显式处理此机制。
5. **Idea2Story / ARS (Xu et al., 2026; Wu, 2026)**：技能化写作辅助工具；定位差异：两者未执行真实实验或生成可编辑矢量图，仅覆盖管线子集。
6. **CycleResearcher (Weng et al., 2025)**：自动化研究者+审查者配对，最接近本工作对抗性审查机制；定位差异：CycleResearcher 不运行端到端实验，也不生成可编辑图表。

## 局限性与未来方向
- **模型依赖的语义判断**：声明证据诊断（claim-level evidence diagnosis）目前仍由 LLM 执行，存在模型判断偏差风险，尚未实现完全自动化验证。
- **成本与时间开销**：全栈运行平均 11.9M tokens、$8.1/篇、3.2 小时，相比单遍草稿（$0.66、16 分钟）仍有显著差距，可能限制高频迭代使用。
- **模板覆盖有限**：当前支持模板依赖手动配置，新venue适配需新增 template specification，尚未实现完全自动化的模板推理。
- **自证伪循环的上限设定**：7 轮循环为经验设定，缺乏对最优阈值的系统分析；部分研究方向可能在第 7 轮后才收敛。
- **评估选题规模较小**：8 个控制选题不足以保证跨领域泛化性结论，案例研究虽有趣但非定量证据。
- **可编辑矢量图重构成功率**：部分复杂图表的重构可能失败并回退至光栅输出，成功率与复杂度关系未系统量化。

## 研究启发与可借鉴点
1. **实验前承诺（Preregistration）机制**：将评估协议（数据集、基线、指标、表格结构）在实验前锁定，可有效防止"后验调整协议"的偏差，适用于任何实验驱动的研究自动化系统。
2. **确定性门控 + 模型批判的双轨架构**：将可机械验证属性（编译、引用解析、表格结构）与需语义判断属性（论据一致性、证据强度）分离处理，兼顾效率与质量，可作为通用研究管线的标准设计模式。
3. **自证伪循环的有界恢复策略**：识别"反复否定同一假设却坚持同一方向"的病态行为，设定迭代上限并生成失败报告而非强行"成功"，对研究代理的可靠性设计具有重要参考价值。
4. **角色感知的图表生成管线**：区分定量结果图（数据驱动）与解释性图表（视觉驱动+代码重构），兼顾生成质量与出版可用性，可迁移至技术报告、教程文档自动生成等场景。
5. **Lean-in 的编程助手集成策略**：复用现有编程助手能力（文件 I/O、代码执行、工具调用）而非构建独立平台，降低部署门槛并提高与研究者工作流的兼容性，为"嵌入式 AI 研究助手"提供可行范式。

## 关键术语表
- **Self-Refutation Loop（自证伪循环）**：系统反复得出结论"实验不支持原假设"却继续修订同一研究方向的行为模式，导致无法收敛到可辩护的科学结论。
- **Preregistration（实验前承诺）**：在观察结果前预先指定实验设计、评估协议与结果表格结构，防止事后调整协议以适应期望结果。
- **Proposal Mode vs. Data-Aware Mode**：前者用于无实测数据的早期提案阶段（未观测结果保持未指定），后者用于有实测数据阶段（定量陈述必须锚定数据）。
- **Deterministic Gates（确定性门控）**：基于显式规则的可机械验证检查（模板合规、引用解析、编译成功等），不依赖模型语义判断。
- **Adversarial Review（对抗性审查）**：多角度独立审查手稿，每条评论须引用具体段落并经三重验证（问题存在性、已解决性、范围合规性）后才被采纳。
- **Editable Vector Figures（可编辑矢量图）**：通过代码（HTML/CSS/LaTeX）重构生成的图表，文本与图形元素保持可编辑性，区别于直接嵌入的光栅图像。
- **Claim Admission Protocol（声明采纳协议）**：将每条声明标记为 SUPPORTED/PARTIALLY-SUPPORTED/UNSUPPORTED/CONTRADICTED/NEEDS-CONFIRMATION，并触发对应修订动作的协议。
- **Result Integrity（结果完整性）**：定量陈述必须可追溯至原始实验 artifact（数据集、配置、种子、日志、测量值），禁止无证据支撑的数值生成。

## 可复现要素
- **数据集/选题**：8 个控制选题（论文未公开具体选题列表与数据；案例研究涉及 Pima Diabetes、Cleveland Heart Disease、Kaggle Stroke 三个公开临床数据集）。
- **代码开源**：是，GitHub 仓库 https://github.com/Spark-To-Paper-Skills/spark-to-paper-skills。
- **模型**：使用 Claude 系列模型（具体子模型未明确，依赖 Anthropic Claude agent SDK）。
- **关键超参**：
  - 自证伪循环上限：7 轮
  - 审查收敛条件：新一轮无新增有效问题
  - 模板配置：按 venue 参数化，非硬编码
- **评估协议**：提案式注册（pre-registered），外部时间戳锁定，无论结果优劣均报告。
