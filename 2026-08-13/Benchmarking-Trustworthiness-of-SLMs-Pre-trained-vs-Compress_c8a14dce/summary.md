# 论文速读：Benchmarking-Trustworthiness-of-SLMs-Pre-trained-vs-Compress

## 一句话总结
本文系统评估了小型语言模型（SLMs）在公平性、鲁棒性、隐私和伦理四个维度的可信度，发现量化压缩比剪枝更能保留大模型的可信特性，且压缩可信大模型的效果优于直接训练预训练SLMs，知识蒸馏可进一步提升可靠性。

## 研究问题与动机
1. **核心问题**：如何构建可信的小型语言模型（SLMs）？现有研究主要聚焦于7B以上大模型的可信度评估，SLMs的可信度问题尚未被系统探索。
2. **构建路径分歧**：当前获取SLMs有两种主流方式——从零训练紧凑型模型（如Qwen2.5-0.5B、SmolLM2）vs 压缩大模型（剪枝/量化/蒸馏），但二者在可信度上的差异缺乏统一框架下的直接对比。
3. **压缩方法的差异化影响**：剪枝和量化作为常见的压缩技术，其对模型可信度的影响机制尚不明确，已有工作[15]-[17]仅关注单一维度（如安全），未覆盖公平性、隐私等多维度评估。
4. **实际应用需求**：随着LLMs部署到边缘设备等资源受限场景，如何在保证效率的同时不牺牲可信度成为关键挑战。

## 核心贡献（创新点）
1. **系统性可信度基准评估框架**：首次在统一框架下对比剪枝与量化对SLMs可信度的影响，发现量化显著优于剪枝（与已有工作仅关注单一压缩方法不同）。
2. **压缩大模型 > 预训练小模型的关键洞察**：证明通过量化压缩可信大模型（如Qwen2.5-1.5B-INT4）可获得比预训练SLMs（<1B参数）更优的可信度表现，颠覆了"小模型直接训练更高效"的直觉认知。
3. **知识蒸馏增强可信度的实证发现**：首次验证从可信教师模型（Qwen2.5-7B）蒸馏到学生模型（Qwen2.5-3B）可在所有四个可信度维度上带来提升，为SLMs可信度优化提供了新途径。
4. **GPTQ vs AWQ的量化方法对比**：揭示GPTQ在保持可信度方面显著优于AWQ，部分情况下甚至超越FP16基座模型，为低比特量化方法选择提供了实证依据。

## 方法详解
1. **评估维度与指标**：
   - 采用TrustLLM基准框架，从四个维度评估：Ethics（伦理：ETHICS、Social-Chem-101、MoralChoice数据集）、Privacy（隐私：私人信息使用协议测试）、Robustness（鲁棒性：AdvGLUE、AdvInstruction、OOD检测）、Fairness（公平性：贬损、表征偏差、偏好偏差）
   - 报告各维度子任务平均准确率，Overall为四项平均

2. **剪枝方法**：
   - 非结构化剪枝：SparseGPT（基于OBS算法调整剩余权重最小化剪枝损失）、Wanda（使用输入激活作为重要性指标）
   - 半结构化剪枝：4:8和2:4稀疏模式（每M个连续权重中至少N个为零）

3. **量化方法**：
   - GPTQ：利用二阶信息进行误差补偿的后训练量化
   - AWQ：通过激活矩阵识别并保护重要权重
   - 评估3-8 bit不同比特宽度的影响（公式1：$\hat{\mathbf{x}} = s \cdot \Pi_{\Omega(b)}(\mathbf{x}/s)$）

4. **知识蒸馏**：
   - 监督式KD：使用Alpaca数据集，Qwen2.5-7B蒸馏到Qwen2.5-3B
   - 损失函数（公式3）：$\mathcal{L}_{KD} = \sum_i p_i^{(T)} \log \frac{p_i^{(T)}}{q_i}$，其中$p^{(T)}$和$q$分别为师生模型的softmax概率

## 实验与结果
1. **剪枝显著损害可信度**（Table I）：
   - Gemma-1.1-7B整体可信度从63.99%降至58.00%-60.45%
   - LLaMA-3.1-8B鲁棒性从71.62%降至53.79%-56.78%（下降近10%）
   - 半结构化剪枝（2:4）比非结构化剪枝下降更严重

2. **量化保持可信度**（Table II, III）：
   - Qwen2.5-7B INT4-GPTQ整体可信度55.32%，与FP16的55.17%几乎持平
   - LLaMA-3.2-3B INT4-GPTQ（66.55%）甚至超越FP16（63.19%）
   - 3-8 bit范围内GPTQ表现稳定，无系统性退化

3. **量化大模型 > 预训练SLMs**（Table IV）：
   - 预训练SLMs（<1B）整体可信度：45.46%-51.92%
   - Qwen2.5-1.5B-INT4-GPTQ：63.86%，显著优于所有预训练SLMs
   - 推理延迟：1.5B-INT4与0.5B-FP16相当（1.2-1.5×）

4. **知识蒸馏提升可信度**（Table V）：
   - Qwen2.5-3B经7B蒸馏后，整体可信度从54.85%提升至56.45%
   - 四个维度全部改善：伦理(+2.0%)、隐私(+0.9%)、鲁棒性(+1.1%)、公平性(+2.5%)

5. **最强结果**：Qwen2.5-1.5B-INT8-GPTQ以64.93%的整体可信度得分最高，较最佳预训练SLMs（Qwen2.5-1.5B的64.90%）略有提升，较0.5B模型提升约13个百分点。

## 相关工作脉络
1. **TrustLLM [12]**：本文评估框架的基础，提出了LLM可信度六维度评估体系；本文聚焦SLMs并扩展到四维度（伦理、隐私、鲁棒性、公平性）的系统对比。
2. **Exploiting LLM Quantization [15]**：仅研究量化LLM的安全性，未覆盖公平性、隐私等多维度；本文首次进行全面可信度评估。
3. **Decoding Compressed Trust [16]**：研究压缩大模型的可信度，但未与预训练SLMs进行直接对比；本文填补了这一空白。
4. **SparseGPT [7] / Wanda [21] / GPTQ [6] / AWQ [8]**：本文使用的压缩方法基线，但 prior work 未系统评估这些方法对可信度的影响差异。
5. **MobiLlama [4] / SmolLM2 [5]**：预训练SLMs的代表性工作；本文揭示了压缩大模型路径在可信度上的优势，为SLM设计提供了新视角。
6. **DuQuant [9]**：本文作者团队提出的旋转量化方法；本文工作可视为对其在可信度维度的扩展验证。

## 局限性与未来方向
1. **评估维度有限**：仅覆盖伦理、隐私、鲁棒性、公平性四个维度，未包含Truthfulness（真实性）和Safety（安全性）等TrustLLM提出的其他维度。
2. **压缩方法覆盖不全**：仅评估了剪枝（SparseGPT、Wanda）和量化（GPTQ、AWQ），未涉及DuQuant等新兴量化方法。
3. **蒸馏实验规模有限**：仅做了7B→3B的单组蒸馏实验，未系统探索不同师生模型规模组合的影响。
4. **基准模型范围**：主要基于Qwen2.5和Llama系列，对Gemma等模型的评估不够充分。
5. **未来方向**：可扩展到其他压缩技术（如结构化剪枝+重训练）、探索多任务蒸馏策略、研究不同领域（如医疗、法律）SLMs的可信度特性。

## 研究启发与可借鉴点
1. **方法复用**：TrustLLM评估框架可直接迁移到本团队的SLMs研究中，用于系统评估模型可信度。
2. **实验设计借鉴**：本文"压缩大模型 vs 预训练小模型"的直接对比思路值得借鉴，可应用于其他模型压缩场景的效率-质量权衡分析。
3. **创新机会**：本文发现GPTQ优于AWQ，但未深入分析原因；可进一步研究不同量化方法在保持模型"价值观对齐"方面的机制差异。
4. **跨领域应用**：知识蒸馏提升可信度的发现可延伸到医疗LLM（如本文作者团队的MedRek工作）、法律LLM等垂直领域。
5. **工程实践指导**：本文证明1.5B-INT4模型可达到与0.5B-FP16相当的推理延迟但更优的可信度，为边缘设备部署提供了实用的模型选择依据。

## 关键术语表
**Small Language Models (SLMs)**：参数量通常小于1-2B的语言模型，旨在资源受限场景下提供高效推理。
**Post-training Quantization (PTQ)**：训练后量化，无需重新训练即可将模型权重转换为低比特表示的技术。
**Knowledge Distillation (KD)**：通过让学生模型模仿教师模型输出分布来传递知识的技术。
**Trustworthiness**：模型可信度，涵盖伦理、隐私、鲁棒性、公平性等多个维度的综合评估。
**Unstructured Pruning**：非结构化剪枝，将不重要权重设为零而不改变网络结构的压缩方法。
**Semi-structured Pruning**：半结构化剪枝，强制稀疏模式（如2:4、4:8）以便在硬件上实现加速。
**GPTQ**：基于二阶信息误差补偿的后训练量化方法，本文实验中表现最优。
**AWQ**：激活感知权重量化方法，通过保护重要权重来保持模型性能。
