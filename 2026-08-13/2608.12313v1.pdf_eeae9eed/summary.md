# 论文速读：AVA-Encoder: Towards Agent-Native Video Representation Learning

## 一句话总结
本文提出 AVA-Encoder，一种面向 AI Agent 的原生视频表征学习框架，通过“盲反向描述 → 原子事实对比 → QA-Reward”三层并行评估体系，结合 Audio/Style/Camera 三维独立评委 Prompt 与 v7.0 伪训练修正策略，将视频质量评估从主观打分转化为可逐条验证的原子事实对账，显著抑制生成幻觉并提升多模态时序保真度。

## 研究问题与动机
- **细粒度事实对齐缺失**：现有视频生成与评测方法多依赖全局相似度或人类偏好排序，无法精确刻画角色微表情、空间拓扑、镜头运动与音频细节等原子级事实。
- **幻觉与因果推断污染**：传统 LLM 驱动的视频理解常基于情节模式推断因果或补全画外信息，导致表征空间引入不可验证的想象内容。
- **多模态维度纠缠**：音频、视觉风格与镜头语言在统一表征中相互干扰，单一评分器难以解耦各维度的独立误差源。
- **Agent 下游消费困难**：缺乏结构化、可机读的 video representation，导致下游 Agent 难以将视频内容转化为确定性约束或可执行奖励信号。

## 核心贡献（创新点）
- **提出三层并行评估流水线**：将盲反向描述、原子事实对比与 QA-Reward 串联为可计算闭环，首次实现视频表征从“模糊相似”到“原子对账”的范式转换。（与已有工作本质区别：不依赖外部人类标注或单一回归分数，而是通过可验证的三态计数与二元 QA 直接驱动优化。）
- **设计 Audio/Style/Camera 三维独立评委协议**：强制核查点限定为“特定时刻可直接指向的可感知事实”，从 Prompt 工程层面切断情节因果推断与幻觉生成路径。（区别于通用视频评测 LLM，该协议输出标准化 JSON 并内置切变检测与负向题目控制，适配 Agent 系统机读需求。）
- **构建带负向探测器的 QA-Reward 系统**：基于 N 帧均匀采样与 Whisper 转写生成原子 yes/no 问题库，强制 25%–40% 题目为负向样本，以 QA 准确率作为强化信号。（与现有 reward model 相比，引入程度二元化与多维度 P0–P4 优先级表，避免过度乐观偏差。）
- **推出 v7.0 伪训练修正策略**：针对物种锁定、解剖描述、镜头缩放参数化、道具正负枚举、多主体空间拓扑量化等 5 类典型失败模式实施硬性规则约束。（与数据驱动的 RLHF 不同，该策略以失败模式图谱为导向，无需额外真人标注即可快速迭代 Agent 描述能力。）

## 方法详解
- **盲反向描述（Blind Back-Captioning）**：要求模型客观罗列 GT 与生成视频的所见所闻，覆盖 Character、Scene、Position、Motion、Audio、Style、Camera、Narrative 八大子维度；每子维度产出 4–6 条具体可验证句子，严禁使用“多个/若干/似乎”等模糊词或画外因果推断。
- **原子事实对比（Atomic-fact Comparison）**：将描述 A（参考）与 B（候选）逐条比对，判定 `hit / conflict / missing`；严格标准规定不同色深判 conflict、左右颠倒判 conflict、B 泛化而 A 具体判 missing；最终输出含各子维度 `n_facts / hit / conflict / missing` 计数的 JSON。
- **三维评委 Prompt 协议**：
  - **Audio**：核查每条台词（角色身份+音色各一项）、旁白、详细音效（每一步伐/关门/衣物摩擦/环境音/动物叫声单独列项）、BGM（二元）；无音记录 `"no speech"`；verdict 四档 `match / partial / mismatch / absent`。
  - **Style**：核查 Broad visual style、时代/介质纹理（胶片颗粒/柔焦）、主导色调（1–2 条）、光线特征（高调/低调/主光方向各单条）、对比度（二元）。
  - **Camera**：核查景别、机位角度、构图、镜头运动类型（`crit=true` 标记）、运动方向与范围；内置切变检测，遇画面跳切时增补 `crit=true` 的“内部切变”核查点并分段评估。
- **QA-Reward 系统**：
  - **问题生成**：输入 N 帧均匀时序采样 + Whisper 转写 + 原文台词，输出原子 yes/no 问题；支持 `visual`（默认）与 `transcript`（音频必用，程序在生成字幕中搜索 4–12 汉字 probe phrase）双模式。
  - **优先级表（P0–P4）**：P0 必答题覆盖角色表情/姿态/身份/服装、镜头运动/主体运动/台词/位置变化/交互；P1–P3 依次补充场景陈设、情绪基调、事件顺序、色调/光线/景别；P4 仅限视觉突出细节且不得超过总题数 20%。
  - **负向控制与二元化**：25%–40% 题目正确答案设为 `no`，优先分布于 P0/P1 与时间维度；所有程度描述强制转化为二元陈述，规避质量评价主观性。
- **Agentic Video Encoder v7.0 伪训练策略**：基于 6 类典型失败模式迭代，实施 5 条强制修正规则：①物种名锁定（禁用 `animal` 等模糊词，强制“精确物种名+关键区分特征”）；②显式解剖描述（非人生物运动相关器官必须具象化）；③镜头缩放参数化+事件锚定（起始景别→运动类型/方向/速度→结束景别，绑定叙事事件）；④场景道具正负枚举（正列重要道具，负排除幻觉项，锁定放置表面/容器）；⑤多主体空间拓扑与量化面积（强制输出相对位置与占据比例）。
