# 论文速读：Mechanist: AI as a Scientific Instrument for Discovering the Mechanisms of Intelligence

## 一句话总结
论文提出 **Mechanist**，一个将 AI 作为科学仪器的多智能体自治框架，通过假设生成、实验执行、结果验证与迭代循环自主挖掘大模型内部机制；并在此基础上揭示了跨模态隐性偏好传递的安全风险、信念状态推理的可分离头机制，以及基于机制干预提升复杂推理与驱动生物序列设计的有效性。

## 研究问题与动机
- **核心问题**：AI 模型能力快速演进，但对其内部机制（如何获取知识、形成信念、推理与行动）的理解严重滞后，且现有自动化研究多聚焦于训练配方优化或具体科学任务求解，缺乏对 AI 智能机制本身的系统性、跨阶段自主探索。
- **现有方法不足**：
  1. 现有 AI Scientist 系统主要输出特定任务的案例级假设或解决方案，无法跨越模型族与预训练/推理阶段提炼理论级机制。
  2. 现有自动化可解释性框架多局限于推理时单个神经元或特征的静态描述生成，缺乏跨行为类型、支持因果验证与迭代修正的机制理论挖掘能力。
  3. 机制探索高度依赖人工设计，难以规模化，导致“模型能做什么”与“我们能否理解/控制它”之间的鸿沟持续扩大。

## 核心贡献（创新点）
1. **提出 Mechanist 自治科学仪器框架**：构建含假设生成、实验执行、结果验证与迭代四个阶段的 Multi-Agent 系统，将人工主导的机制探索流程转化为可自动执行的科研循环。*本质区别在于以 AI 模型自身为研究对象，输出跨模型与跨阶段的行为机制理论，而非单一任务的性能优化。*
2. **构建双源知识基础设施与 32 方法库**：打造约 1.3 万篇论文聚焦的可解释性知识图谱与涵盖 26 个学科 4300 万篇论文的跨学科知识库，并 curated 11 类、32 种机制分析方法的基础库。*区别于传统文献检索，支持语义-结构-图拓扑的多通道检索与假设 grounded 生成，填补了自动化机制探索的知识底座空白。*
3. **发现跨模态隐性偏好传递的新安全风险**：证明不安全特质可通过表面上完全安全的训练数据在跨模态（文本→图像）场景中长期潜伏并传递，突破了单模态中性数据的已有发现。*首次将 subliminal learning 拓展至语义相反的跨模态设定，揭示基于内容的过滤机制无法阻断隐性风险传播。*
4. **提出信念状态推理的机制理论并实现动态干预**：在 Pythia 与 OLMo 系列中定位出稀疏且可分离的 AB write head 与 PB correction heads，追踪其随预训练逐步涌现的过程，并据此设计轻量级 probe 引导的头显式放大干预。*将认知科学中的 belief-state 区分操作化至 LLM 内部组件，实现从机制发现到可控增强的闭环。*
5. **拓展至跨学科机制设计应用**：在科学基础模型 Evo2-7B 上识别与 α-螺旋结构相关的内部特征，通过因果激活直接引导 DNA 序列生成，替代高计算成本的 generate-and-rerank 范式。*展示机制可解释性向生物学实验设计转化的可行性，推动可解释性从“分析工具”走向“设计工具”。*

## 方法详解
- **多智能体架构**：中央 Orchestrator 解析研究目标、资源约束与调度要求，按序派发四个专属 Agent。各 Agent 运行于隔离上下文，通过工作区显式工件（proposal、experiment plan、tracker、code、results、integrity report）进行跨阶段通信，支持断点续跑。
- **Hypothesis Agent**：将用户意图分解为领域子查询，分别从可解释性图谱与 SciAtlas 跨学科图谱检索；结合 HyDE（生成假想摘要）进行语义对齐，输出原子化假设声明（现象是否存在/机制是什么/如何应用）与里程碑测试计划。
- **Experiment Agent**：将候选声明实例化为可执行实验，明确数据集划分、目标模型、可解释方法、评估指标、对照组与算力预算；内置 32 种机制分析方法（覆盖词汇投影、幅度分析、表征/参数分析、探针、特征字典学习、梯度检测、因果归因、电路发现、SHAP、神经特征学习、多模态专项等 11 家族），并在部署前进行轻量 sanity check 防止算力浪费。
- **Verification Agent**：审计标签来源、数据泄漏、指标有效性；对有效结论进行泛化与鲁棒性检验（替换方法/数据集/模型后验证稳定性），确保结论不依赖单一实验配置。
- **Iteration Agent**：结合 Verification 诊断与 GPT-5.4 独立审查，判断假设范围/假设表述或实验设计/执行需修订，分配至对应 Agent 重跑，直至达到收敛或修复合计上限。
- **记忆管理**：外部化结构化记忆，迭代期使用 append-only reviewer memory 记录历史关切，compact review-state file 记录修复合计进度；跨轮次维护 global memory 存储已验证结论与未尝试方向，避免重复工作。
- **检索策略**：Query 分解→多通道匹配（BM25 关键词、稠密向量、标题精确/模糊匹配）→图拓扑受限多跳扩展→RRF
