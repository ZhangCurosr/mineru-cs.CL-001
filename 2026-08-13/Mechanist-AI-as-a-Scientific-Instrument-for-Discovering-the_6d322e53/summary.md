# 论文速读：Mechanist: AI as a Scientific Instrument for Discovering the Mechanisms of Intelligence

## 一句话总结
本文提出 Mechanist，一个将 AI 作为科学仪器的多智能体框架，能够自主完成“假设生成-实验执行-结果验证-迭代修正”闭环以发现 AI 模型的内在机制；该系统在 16 篇论文复现基准上显著优于 Claude Code 与 AI-Scientist，并成功演示了从跨模态安全风险发现、信念机制理论建立、动态头部干预到 DNA 序列定向设计的完整研究推进链条。

## 研究问题与动机
- AI 模型能力快速演进，但其内部工作机制、知识获取与信念形成过程仍高度黑箱，手动机制探索严重滞后于模型迭代速度。
- 现有 AI Scientist 类系统主要面向训练配方优化或特定外部科学任务（如药物发现、材料合成），而非 AI 模型自身的可解释性机制挖掘。
- 现有自动可解释性工具多局限于推理时单个神经元或特征的静态描述，缺乏跨越预训练与推理阶段、覆盖多种行为并支持因果验证的通用机制理论探索能力。
- 需要一种既能承接人类科学目标设定、又能规模化执行假设-实验-验证闭环的自动化科研基础设施，以 bridging 模型能力与可理解性之间的鸿沟。

## 核心贡献（创新点）
- **提出 Mechanist 多智能体科研框架**：由编排器与假设生成、实验执行、验证、迭代四个专用 Agent 构成，实现端到端自主机制发现。与已有 AI Scientist 的本质区别在于研究对象从“外部科学任务/训练配方”转向“AI 智能本身的内在机制与行为因果”。
- **构建双源知识资源体系**：自建约 1.3 万篇论文的可解释性专属知识图谱（覆盖研究对象、应用场景、分析方法三轴），并融合 SciAtlas 跨 26 个学科、4300 万篇文献的宏观数据库。区别于单一文献库检索，本工作支持细粒度概念对齐与图结构多跳扩展。
- **集成 32 种模块化机制分析方法库**：涵盖词汇投影、显著性分析、表示工程、探针、稀疏自编码器、梯度检测、因果归因、电路发现等 11 大类，每类附带可执行代码、适用边界与常见失败回退策略。现有工作多为孤立方法堆砌，本文将其标准化并接入 Agent 决策流。
- **四层次实证推进与系统性评估**：在 16 篇机制论文盲跑复现上全面领先基线；通过安全行为发现、信念机制理论、动态干预优化、生物序列定向设计四个递进案例，证明系统可从现象描述跨越至因果控制与跨学科应用。

## 方法详解
- **多智能体协同架构**：Orchestrator 解析研究目标、资源约束与调度需求，顺序派发给四个 Agent；各 Agent 运行于隔离上下文，通过工作区显式产物（提案、实验计划、追踪器、代码、结果、完整性报告）通信，支持中断恢复与长期记忆沉淀。
- **假设生成 Agent**：采用多源检索策略，将用户意图分解为领域子查询，在可解释性图谱与跨学科图谱中进行混合检索；结合 HyDE 生成领域术语假设性摘要以提升语义召回；最终将假设表述为原子声明并规划里程碑式测试。
- **实验执行 Agent**：将候选声明实例化为可执行实验套件，明确数据集划分、目标模型、分析方法、评估指标、对照设置与算力预算；内置 32 种方法规则、显式数据选择规范与内存感知调度，并在全量部署前执行轻量级合理性检查。
- **验证 Agent**：审计标签溯源、数据泄露、指标有效性及结果可追溯性；对可靠结论进行跨方法、跨数据集、跨模型的泛化与鲁棒性测试，若实验不可靠或结论不稳定则触发迭代。
- **迭代 Agent**：结合验证诊断与独立 LLM 审阅，判断需修正假设还是实验设计，并将问题路由回对应 Agent 重跑，直至验证通过或修订预算耗尽。
- **检索与排名策略**：查询分解→多通道匹配（BM25 关键词、语义向量、标题精确/模糊匹配）→基于引用与领域关系的受控多跳图扩展（限制深度与节点数防语义漂移）→RRF 融合后按相关性、图支持度、引用影响力、发表时间、标题匹配度加权重排。
