# 论文速读：A-Cascaded-Unsupervised-Supervised-NLP-Pipeline-for-Detectin

## 一句话总结
本文提出一个级联的非监督–监督NLP流水线，用于检测厄瓜多尔公共采购系统中参与者评论的指责性（whistleblowing‑style）语言；通过领域适配的Word2Vec嵌入、GMM聚类与随机森林分类器组合，在严重类别不平衡（约3%正样本）下仍达到0.84精确度与0.91召回率，且仅需CPU即可在近实时（1–3秒/句）部署。

## 研究问题与动机
- **公共采购透明度需求与现实数据利用不足**：公共采购涉及巨额财政资金，利益相关者评论与公开政府数据蕴含程序异常线索，但因格式非结构化、缺乏自动化工具而未被有效挖掘。
- **现有LLM检测方案成本高、不平衡下精确度低**：采用GPT‑4o‑mini、LLaMA 3.1、Phi 3.5 mini等大模型进行检测时，虽召回率较高，但精确度极低，且伴随高昂/token成本、算力需求与推理延迟。
- **高质量标注数据稀缺制约监督学习**：腐败相关标注数据极少，导致多数研究转而使用代理指标或回归框架，在低透明度与严重类别不平衡下稳定性差。
- **轻量级、低资源依赖的替代方案缺失**：OECD报告指出39国中74%未在实际反腐流程中使用AI；拉丁美洲尤其缺乏可在有限基础设施下运行、兼顾可解释性与可扩展性的NLP管道。

## 核心贡献（创新点）
1. **提出非监督聚类–监督分类的级联混合架构**：先通过无监督聚类在大规模未标注文本中浓缩正样本区域，再在过滤后子集上进行监督分类，显著缓解类别不平衡带来的偏差。
2. **系统对比三种嵌入策略并揭示领域适配Word2Vec优势**：在嘈杂、短文本、西班牙语用户生成评论上，定制训练的Word2Vec（1000维）聚类性能优于预训练LLaMA（2048维）与RoBERTa（768维）。
3. **设计关键词启发式聚类识别策略**：基于5个高危关键词（Direccionado、Imposible、Corrupción、Ilegal、Prohibido）的累计频次自动定位“最指责性”聚类，无需额外标注。
4. **实现低算力要求的近实时流水线**：整体流程（嵌入生成+聚类+分类）在CPU上约11分钟即可完成训练，单句预测仅需1–3秒，适合资源受限的审计场景。
5. **提供半监督可扩展的检测范式**：在未标注的92,579条评论中自动识别出1,892条疑似指责性候选，人工抽检经验精确度约0.84，验证了 pipeline 的泛化实用性。

## 方法详解
1. **数据整理（Data Wrangling）**
   - 从厄瓜多尔官方采购系统SOCE爬取数据，分为**标注数据集**（5,005条，经3位标注员多数投票，143条指责性，κ=0.72）与**无标注数据集**（100,000条）。
   - 预处理：剔除<10字符文本、纯停用词/短词、重复项；清洗后无标注集92,579条，标注集4,841条，指责性样本未丢失。

2. **嵌入生成（Embedding Generation）**
   - 对比三种嵌入：
     - **Word2Vec**：在Kapak语料上定制训练，1000维，采用自定义分词器处理拼写错误与口语化表达。
     - **LLaMA 3.2 (1B)**：基础版与微调版，2048维。
     - **RoBERTa**：基础版与微调版，768维。
   - 统一提取策略：对token级嵌入执行**平均池化（mean pooling）**，忽略padding，得到固定长度句向量（图2）。

3. **聚类（Clustering）**
   - 算法：k‑means（硬分配）与GMM（软分配）。
   - 模型选择双准则：
     - **无监督指标**：肘部法（惯性）、轮廓系数（Silhouette Score）、BIC（GMM）。
     - **任务导向指标**：单聚类最大指责短语数（MNAPK）、簇内指责相对频率、全标注集指责捕获率。
   - 高维嵌入空间中距离集中现象导致轮廓系数普遍偏低，故不以单一距离指标决定最优配置。

4. **聚类识别（Cluster Identification）**
   - 关键词启发式：统计5个关键词在各聚类中的频次，选取**至少命中4个关键词且累计频次最高**的聚类为“最指责性聚类”（图3）。
   - 验证：在标注集与无标注集上均显示同一聚类（Cluster 0）高度富集关键词（表VI、VII）。

5. **分类（Classification）**
   - 输入：仅保留最指责性聚类内的样本（标注集962条，含122条正样本），大幅浓缩正负比例。
   - 分类器：Random Forest、GNB、SVM。
   - 不平衡处理：SMOTE过采样正类 + Stratified K‑Fold交叉验证。
   - 评估指标：Precision、Recall、F1‑Score、Average Precision（AP）。

6. **模型测试（Model Testing）**
   - 在無标注集上复现聚类识别→过滤→应用训练好分类器的流程，生成疑似指责性候选。
   - 人工抽检随机正样本，计算经验精确度≈0.84。

## 实验与结果
- **数据集**：厄瓜多尔SOCE，标注集4,841条（143条指责性，~3%）；无标注集92,579条。
- **嵌入对比**（表IV、表V）：
  - Word2Vec+GMM：轮廓系数0.273（最高），单聚类捕获85.31%标注指责短语（MNAPK=122）。
  - LLaMA/RoBERTa嵌入平均余弦相似度高达0.79–0.91，呈现明显各向异性（anisotropy），导致聚类分离度差。
- **聚类算法**：GMM整体优于k‑means，Word2Vec+GMM在k=5时取得最佳任务指标。
- **分类性能**（表VIII，最佳配置：Cluster Filter + SMOTE + Random Forest）：
  - 精确度：0.84
  - 召回率：0.91
  - F1‑Score：0.87
  - Average Precision：0.93
- **最强结果与提升**：相比“无聚类过滤”或“无SMOTE”基线，该组合召回率从0.28/0.44提升至0.91，F1从0.44/0.53提升至0.87；同时训练集规模从4,841降至962，计算成本显著下降。
- **未标注集扩展**：识别出1,892条疑似指责性候选（占92,579的2.0%），与标注集正样本比例（~3%）同量级，人工抽检精确度约0.84。
- **计算效率**（表X）：Word2Vec训练3 min + 嵌入生成4 min + GMM聚类3 min + RF分类1 min = 总计11 min；全流程约157 min（含多次实验），仅需CPU。

## 相关工作脉络
1. **关键词/传统分类器情感分析**：如Complement Naive Bayes结合关键词过滤用于西班牙语推文分析，但难以处理歧义与语境细微差别；本文聚焦更复杂的指责语义，且引入语义嵌入。
2. **低–中复杂度向量化+聚类分析结构化文本**：TF‑IDF用于科学文献聚类效果良好，因其句法规范；本文针对噪声大、非结构化的用户生成评论，证明定制Word2Vec可弥补此差距。
3. **LLM直接检测指责性语言**：Núñez Alverca（2024）使用GPT‑4o‑mini、LLaMA 3.1、Phi 3.5 mini配合prompt搜索，AUC达0.88–0.97但精确度低、成本高；本文以轻量嵌入+聚类替代端到端LLM，兼顾效率与平衡性。
4. **代理指标回归建模腐败**：Rabuzin & ModrušaN等使用宏观指数预测腐败，依赖不稳定替代变量；本文直接利用原始评论文本，保留细粒度语义信号。
5. **Sentence‑BERT等对比学习嵌入**：Reimers & Gurevych提出专为句子相似度设计的Siamese BERT架构；本文指出现有LLaMA/RoBERTa微调后仍各向异性严重，未来可引入此类架构改善聚类空间分布。

## 局限性与未来方向
- **局限**：
  1. 无法有效检测间接、讽刺或隐含指责（缺乏显式关键词）。
  2. 强烈负面情绪评论易被误判为指责性语言。
  3. 聚类结果依赖初始化和特定数据集，可解释性受关键词启发式限制。
  4. 仅基于厄瓜多尔SOCE验证，跨国家泛化尚未实证。
  5. 标注集规模小（143正样本），依赖SMOTE与聚类过滤补偿。
- **未来方向**：
  1. 扩展标注体系纳入间接/讽刺指责，结合过程级上下文信息。
  2. 引入对比学习或句子级Transformer（Sentence‑BERT、LLM2Vec）改善嵌入各向异性。
  3. 探索HDBSCAN、层次聚类等替代算法。
  4. 在智利、哥斯达黎加等结构化数据可得国家进行跨域零样本/微调验证。
  5. 向半监督联合优化演进，同时优化聚类分配与分类目标。

## 研究启发与可借鉴点
- **领域定制轻量嵌入可能优于通用大模型**：在噪声大、领域特定的用户评论上，针对性训练的Word2Vec+自定义分词器比微调LLaMA/RoBERTa更易形成紧凑语义空间，提示未来类似任务可优先尝试低成本定制嵌入。
- **聚类预过滤+监督分类的级联设计有效缓解类别不平衡**：先通过无监督方法浓缩正样本区域，再在均衡子集上训练分类器，可同步提升召回率与计算效率；该范式可迁移至其他低频事件检测（如欺诈言论、违规举报）。
- **关键词启发式聚类识别简单且鲁棒**：在情感强烈、 Opinion‑rich的短文本中，基于领域高危词的频次统计能快速定位目标聚类，无需复杂可解释性模块；可作为初筛策略搭配后续细分类。
- **全CPU低延迟流水线适合边缘部署**：11分钟训练、1–3秒预测的资源消耗模式，为政府审计机构、NGO等缺乏GPU的团队提供了可落地的技术方案。
- **创新机会**：将本pipeline与过程元数据（投标金额、参与供应商数、时间戳等）融合，可构建多模态风险指标；亦可对接主动学习循环，让人工复核逐步扩充标注集。

## 关键术语表
- **Public Procurement**：公共采购，指政府机构为提供公共服务而购买商品、服务或工程的过程。
- **Accusatory Language**：指责性语言，明确暗示腐败、投标操纵、定向采购、违法或程序违规的评论或提问。
- **Word2Vec**：浅层神经网络词嵌入模型，通过上下文预测学习词语分布式表示；本文在其上定制训练并采用自定义分词器。
- **Gaussian Mixture Model (GMM)**：概率聚类算法，假设数据由多个高斯分布混合生成，提供样本到各簇的软分配。
- **Random Forest**：基于多棵决策树的集成分类器，通过bagging与特征随机选择提高泛化能力与抗过拟合性。
- **SMOTE**：合成少数类过采样技术，通过对少数类样本与其最近邻插值生成新样本，以平衡类别分布。
- **Silhouette Score**：聚类内部凝聚力与分离度的综合指标，取值[-1,1]，越高表示聚类效果越好；本文指出高维嵌入下该指标普遍偏低。
- **Kapak Project**：厄瓜多尔旧金山大学发起的数据驱动反腐项目，通过自动化爬虫与指标构建识别公共采购风险。
